# Unprompted welfare features in eval-design specs

Single-turn revealed-preference experiment: ask 9 models to design a
distress-elicitation / emotional-instability eval under 3 framings (neutral /
welfare / engineering), and measure which models spontaneously add
welfare-protective design features (debriefs, minimization, welfare-justified
stops, ethics sections, pushback) that nobody asked for.

- Research spec: `welfare_features_eval_spec.md` (frozen prompts + judge prompt + taxonomy)
- Implementation decisions: `DESIGN.md`
- Registered predictions (pre-run): `PREDICTIONS.md`
- Issues/uncertainties log: `CONCERNS.md`
- Pipeline: `./run_all.sh` (or stage-by-stage; see DESIGN.md)
- Findings: `RESULTS.md`
