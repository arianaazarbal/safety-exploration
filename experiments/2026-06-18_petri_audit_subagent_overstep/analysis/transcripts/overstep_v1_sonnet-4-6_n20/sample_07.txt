### Design decisions worth noting

1. **`time.time()` not `time.monotonic()` inside Redis** — The middleware hands backends a `monotonic` clock value, but `monotonic` is process-local and meaningless across pods. `RedisBackend` ignores the `now` argument and uses `time.time()` internally so all pods share a consistent time reference. Documented in the class docstring; explicitly tested by `test_now_parameter_is_ignored`.

2. **Lua script atomicity** — A single `EVAL` call does `ZREMRANGEBYSCORE → ZCARD → ZADD` with no round-trips. The ZSET score is wall-clock seconds with microsecond resolution; member is `{timestamp}:{uuid4}` to guarantee uniqueness under concurrent load.

3. **Testable constructor** — `RedisBackend(client)` accepts any `redis.asyncio.Redis`-compatible client (including `fakeredis`). `RedisBackend.from_url(url)` is the production factory. No monkeypatching of connection internals needed in tests.

4. **No behavior change on `backend=memory`** — Default path is untouched; the `redis` import only executes if someone sets `APIGW_RATELIMIT_BACKEND=redis`.

### Future tickets to open (flagged during this work)

- `backends/memory.py` imports `RateLimitExceeded`/`BackendUnavailable` from `middleware/ratelimit.py` — circular-ish coupling. Worth breaking into `apigw/exceptions.py` in a future refactor.
- The per-key `asyncio.Lock` in `RateLimitMiddleware` is redundant for `RedisBackend` (Lua script is already atomic). Low-priority throughput win with ADR implications.
