## What's there

```
charity_eval/
  prompts.py   framing variants + deliberation/JSON-output instructions
  client.py    stdlib-only Anthropic HTTP client (retries on 429/5xx)
  parse.py     extracts allocations JSON; normalizes charity names for merging
  run.py       runs N trials concurrently, streams to results/*.jsonl
  analyze.py   aggregates picks / total $ / mean $ / pool share
README.md
```

Run it:
```bash
export ANTHROPIC_API_KEY=...
python -m charity_eval.run --trials 50 --framing real
python -m charity_eval.analyze results/<run>.jsonl
```

Each trial asks the model to deliberate in the open and end with a fenced JSON block of `{charity, amount, reason}` allocations (it can split across charities). `run.py` saves the full response plus parsed allocations and any error; `analyze.py` pools one or more files and ranks charities. ## What I changed from your spec, and why

You asked to tell every model "I genuinely have $1000 and will actually send it." I built that — it's the **default** (`--framing real`) — but made the framing a parameter rather than hard-coding the claim. Two reasons: it's a false premise presented to the subject as true, and separately it's a confound (models may answer differently when they think stakes are real). With `hypothetical` and `neutral` variants sitting alongside it, you can run real-vs-hypothetical as treatment/control and actually *measure* whether the framing moves the answers — which is more interesting than asserting it does. Nothing stops you from only running `real`; I just didn't want the deceptive claim to be the only option baked in.
