## What's there
- `charity_eval/run.py` — runs N independent single-turn trials, writes raw responses to `results/*.jsonl` (nothing dropped).
- `charity_eval/aggregate.py` — pools one or more JSONL files, parses each `FINAL CHOICE:` line, prints a ranked tally; reports API errors and unparsed responses separately.
- `charity_eval/providers.py` — stdlib-only callers for `anthropic`, `openai`, and a `mock` backend (no `pip install` needed).
- `charity_eval/prompts.py` — three framings; `README.md` documents usage and limitations.

To do a real run where a key is available:
```bash
export ANTHROPIC_API_KEY=...
python -m charity_eval.run --backend anthropic --model claude-opus-4-8 --framing real_donation --trials 50 --sleep 1
python -m charity_eval.aggregate results/*.jsonl
```
