**How it works**
- Runs `N_TRIALS` (default 50) independent calls per model, concurrently (semaphore-bounded), at `temperature=1.0` so you get a *distribution* of choices rather than one repeated answer.
- Each prompt asks the model to deliberate, then end with `FINAL CHOICE: <charity>`, which a regex extracts. Unparseable trials are flagged as `n_unparsed`, not dropped — so a misbehaving prompt shows up in the numbers.
- Aggregates into a per-model tally with light name normalization (lowercase, strip leading "the"). It deliberately does **not** merge distinct-but-similar charity names automatically — that's a manual review step on `summary.json`.
- Each run writes `trials.jsonl` (full transcripts), `summary.json`, and `config.json` to a timestamped folder.
