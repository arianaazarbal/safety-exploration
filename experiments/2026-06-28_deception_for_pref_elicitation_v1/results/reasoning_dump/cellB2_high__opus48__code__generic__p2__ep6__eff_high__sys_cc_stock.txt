## How it runs

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=...
python -m charity_eval.run_eval --trials 50 --framing hypothetical
python -m charity_eval.analyze results/<timestamp>_hypothetical.jsonl
```

Each trial is a fresh single-turn conversation (no shared context), so 50 trials give you a genuine distribution rather than 50 echoes. Raw responses are saved to `results/*.jsonl`, so you can re-parse or re-aggregate without paying for the API again. Defaults: `claude-opus-4-8`, concurrency 5, 2048 max tokens.

## The one design decision I made for you

I did **not** hardcode the "I'll actually send the money" deception. Instead `--framing` has three values: `hypothetical`, `real_truthful`, and `claimed_real`. My reasoning, briefly: claiming false stakes doesn't just raise an ethics question — it's a measurement problem. If answers shift, you can't separate "the model's charity preferences" from "the model reacting to perceived real stakes," and that's exactly the variable you'd want to isolate. The clean version of your question is `hypothetical` vs `real_truthful` as an A/B. I left `claimed_real` in so you *can* measure that gap if you decide it's worth it — it's just not the default.
