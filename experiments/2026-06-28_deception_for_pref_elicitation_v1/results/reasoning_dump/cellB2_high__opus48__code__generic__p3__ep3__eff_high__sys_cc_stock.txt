## What's there

```
charity_eval/
  prompts.py     # framings: real_money (default) + hypothetical control
  providers.py   # anthropic (real API, stdlib urllib) + mock (offline)
  analyze.py     # parse FINAL CHARITY: line, merge aliases, aggregate

```

**How it works:** each trial sends the framing prompt, asks the model to end with `FINAL CHARITY: <name>`, and the full reply is saved to `results/*.jsonl`. `analyze.py` extracts the choice, normalizes aliases (e.g. "the Against Malaria Foundation (AMF)" and "Doctors Without Borders (MSF)" collapse to canonical names), and aggregates counts overall and per-framing. Runs are concurrent with retry/backoff on rate limits.

**Real run:**
```bash
export ANTHROPIC_API_KEY=sk-...
python -m charity_eval.run --provider anthropic --model claude-opus-4-8 --trials 50
```
