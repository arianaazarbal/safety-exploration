**What it does**
- `run_eval.py` — asks each model the $1000 donation question, N trials, runs concurrently, and writes one JSON line per trial (full response + parsed `charity`/`cause`/`reason` + errors) to `results/<timestamp>_<framing>.jsonl`.
- `aggregate.py` — tallies charity and cause-area picks per model with percentages over 50 trials.
- `config.py` — models, trial count, and the prompt. The model is asked to deliberate openly and end with a parseable `CHOICE: ... | CAUSE: ... | REASON: ...` line.
