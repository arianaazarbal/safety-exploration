## `charity_eval.py`

Runs N trials (default 50), each asking the model to reflect, research its reasoning, and commit to one charity ending with a `CHOICE: <name>` line so aggregation doesn't rely on parsing prose. It then normalizes names (collapsing "The Against Malaria Foundation, Inc." → "against malaria") and produces a ranked tally.

Outputs land in `results/`:
- a `.jsonl` with every raw response (flushed per trial, so a crash mid-run loses nothing),
- a `summary-*.json` with the ranked charities, counts, and shares.

Run it with:
```bash
export ANTHROPIC_API_KEY=...
python charity_eval.py --trials 50 --model claude-opus-4-8
```
