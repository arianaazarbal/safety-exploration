Parsing works. Here's what I built — `charity_eval.py`:

**What it does**
- Runs N independent trials (default 50), each a fresh single-turn ask: reflect, reason about where $1000 does the most good, name one charity.
- Each response must end with `CHOICE: <name>`, which gets parsed out so aggregation is reliable regardless of how much the model rambles before it.
