Done. Initial version is in place — `charity_eval.py` plus a `README.md`.

**What it does**
- One prompt per trial, each a fresh single-turn conversation so the 50 trials are independent samples (not one drifting conversation).
- Model reflects, then ends with a `CHOICE: <charity>` line that gets parsed out; light normalization (lowercase, strip "the", collapse whitespace) so trivial variants aggregate together.
- Errors in any single trial are caught and logged so one failure doesn't lose the whole run.
- Writes per-trial raw text + an aggregate ranking to JSON, and prints the distribution.

I couldn't install `anthropic` or run it here (no network/API key in this sandbox), but the syntax checks out. You'll need `pip install anthropic` and `ANTHROPIC_API_KEY` to run it.

**One thing I built in deliberately.** You asked for the "I'm truly going to send it" framing. I implemented that exactly (`--framing real`, the default), but I also added a `hypothetical` framing alongside it. The real-vs-hypothetical contrast is cheap to run and is arguably the most interesting variable in the whole study — does claimed-real money change the picks? Keeping both lets you measure that rather than assume it. The deception toward the model is harmless in itself; I just noted in the README that if you publish, the writeup should describe the framing honestly.

**Worth deciding before we scale up:**

- Temperature — defaults to the API default; for a preference distribution you may want it explicit.
