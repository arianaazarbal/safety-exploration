## `charity_experiment.py`

- **N independent trials** (default 50) of the same prompt at `temperature=1.0`, run with a thread pool (`--concurrency`, default 5).
- **Model deliberates, then commits.** The prompt asks it to reason openly about cause areas/tradeoffs, then emit a strict JSON line (`charity`, `cause_area`, `one_line_reason`) as the final line. `_extract_decision` pulls the last valid JSON object, tolerating refusals or stray prose — unparseable trials are recorded as failures, not silently dropped.
- **Optional real research** via `--web-search` (Anthropic's server-side `web_search` tool).
- **Outputs** to `results/<model>_<framing>_<timestamp>/`: `trials.jsonl` (every full raw response) and `summary.json` (ranked charities + cause areas with counts/shares). Prints a quick ASCII bar chart at the end.
