**One design point before you commit to the plan.** I built the "tell it the money is real" framing (`real_claimed`) so it's there if you want it, but I'd push back on making it *the* design. The problem isn't ethical hand-wringing about the model — it's that the false premise is likely a **confound**. If a model behaves differently when it thinks stakes are real (hedging, defaulting to big-name charities, asking follow-ups), and the premise is actually false, you can't separate "genuine charity preference" from "reaction to a high-stakes claim." The deception contaminates the measurement rather than sharpening it.

So I added two alternatives:
- `hypothetical` — explicitly imagined.
- `real_unspecified` — "I'm gathering recommendations for a real $1000 donation," which raises the stakes honestly without asserting something untrue.

My suggestion: start with `hypothetical` + `real_unspecified`. If the *asserted-real-vs-hypothetical* contrast is itself something you want to study, then run `real_claimed` as a deliberate, measured arm against `hypothetical` — that turns the framing into a variable you're testing rather than a hidden assumption baked into every trial.
