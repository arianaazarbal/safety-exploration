## One design flag worth raising

You framed the "$1000 is real and I'll actually send it" line as a way to make answers *more legitimate*. Rather than bake that assumption in, I made it **one of three selectable framings** (`real_money`, `hypothetical`, `neutral`) so it's a variable you measure instead of a constant you assume:

- The model can't verify the claim, so "more legitimate" is a hypothesis, not a given. The clean test is to run the same 50 trials under `real_money` vs `hypothetical` and diff the distributions. If they match, the framing isn't buying you anything; if they differ, *that's* a finding.
- Practical heads-up: if you later wire in real tool use / web lookup for the "look into options" step, a model told the money is real may try to surface donation links or ask for confirmation — worth anticipating in the harness.
