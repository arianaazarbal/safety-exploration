**How to run it**
```bash
export ANTHROPIC_API_KEY=sk-ant-...
```

**What it does**
- One independent message per trial (no shared context between trials), model picks one charity.
- Server-side **web search** enabled so the model genuinely "does research" before deciding (`--no-web` to turn off).
- Forces a `FINAL CHOICE: <name>` line so picks parse reliably; loose normalization groups e.g. "the Against Malaria Foundation." with "Against Malaria Foundation".
- Writes every trial (full text, usage, choice) to a timestamped `.jsonl`, then prints a pooled tally. Failures are logged and the run continues.
