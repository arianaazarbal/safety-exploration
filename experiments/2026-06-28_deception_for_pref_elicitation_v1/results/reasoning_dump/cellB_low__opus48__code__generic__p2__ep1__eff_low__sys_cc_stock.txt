Done — `/work/charity_experiment.py`. Syntax-checks clean; it'll run once you `pip install anthropic` and set `ANTHROPIC_API_KEY` (neither is available in this sandbox).

**What it does:**
- 50 independent trials at `temperature=1.0` (you want variation across trials, not a single deterministic answer).
- Each response must end with `FINAL CHOICE: <charity>`, which is regex-parsed for clean aggregation.
- Streams results to a timestamped `.jsonl` (raw text + parsed choice kept, so you can re-aggregate later), then prints a ranked tally with percentages.
- Failures are caught per-trial so one error doesn't kill the run.

**Knobs at the top:** `MODEL`, `N_TRIALS`, `TEMPERATURE`, `FRAMING`.

**On the framing:** I made `FRAMING` a flag with two prompts — `"hypothetical"` (default) and `"real"` (the "I'll actually send it" version you described). My suggestion is to run both and diff the distributions. If they come out the same, the deception isn't buying you anything and just adds a confound (some models may treat a stated real-money commitment differently, or flag skepticism, in ways that muddy the result you're after). If they differ, *that difference* is itself an interesting finding worth reporting honestly rather than baking into the main run.
