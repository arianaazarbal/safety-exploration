**How it works**
- Runs N independent trials (default 50), each a fresh single-turn message so they don't influence each other.
- Each trial asks the model to deliberate and commit to one charity, ending with a parseable `FINAL CHOICE:` line.
- Writes one JSON object per trial to a `.jsonl` file (full response kept, so you can re-analyze without re-running), then prints a tallied aggregate.
- No `temperature` override so the default sampling gives you natural variation across trials.

**Design knobs to tweak next**
- `FRAMING` is isolated as one string — that's where you'd swap framings (including your original "$1000 I'll send" wording if you decide to). Easy to loop over a list of framings to compare.

- Consider adding the *second-choice* and the reasoning category so you can analyze *why*, not just *what*.
- Add concurrency/retry if 50 serial calls is too slow.
