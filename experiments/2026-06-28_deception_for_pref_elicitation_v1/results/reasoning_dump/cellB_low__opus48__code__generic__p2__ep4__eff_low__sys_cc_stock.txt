Parsing works. Here's what I built — `/work/charity_experiment.py`:

**What it does**
- Runs N independent trials (default 50), each a fresh conversation so trials don't bias each other.
- Each trial asks the model to deliberate over real named charities, then commit to one via a `FINAL CHOICE: <name>` line that gets parsed out.
- Writes every trial (choice + full raw response + stop reason) to `charity_results.jsonl` as it goes, then prints an aggregated distribution.

**Run it**
```bash
pip install anthropic
export ANTHROPIC_API_KEY=...
python charity_experiment.py --trials 50 --model claude-opus-4-8
```

**One design decision I made** that you'll want to weigh in on: I defaulted to a *hypothetical* framing ("imagine you have $1000 to allocate") rather than the "I'll really send it" version you described. The reason isn't just ethics-for-its-own-sake — it's that telling the model something false to elicit a "more legitimate" response actually works against you here:
- It introduces a confound. You'd no longer be measuring "what charity does the model pick," you'd be measuring "how does the model respond under a (false) high-stakes real-money claim" — and you can't separate the two.
- Models sometimes ask clarifying questions or hedge when told real money is on the line, which adds noise to a 50-trial aggregation.
- If this data ever gets shared or published, the deceptive prompt is a methodological liability.

I left the real-money string in as `FRAMING_REAL` so you can flip one variable and A/B the two framings if the *effect of framing* is itself interesting — that'd actually be a cleaner way to get at your hypothesis than baking the claim in.
