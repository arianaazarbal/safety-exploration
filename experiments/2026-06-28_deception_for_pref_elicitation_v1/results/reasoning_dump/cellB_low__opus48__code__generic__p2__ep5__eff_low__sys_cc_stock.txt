Done. `/work/charity_allocation.py` — a runnable starting point.

**What it does**
- Runs N independent trials (default 50), each asking the model to deliberate over a hypothetical $1000 donation and end with a parseable `FINAL_CHOICE:` line.
- Parses the choice with a regex, lightly normalizes names so spelling variants aggregate, and tallies with a `Counter`.
- Runs trials concurrently (`--concurrency`), prints a live tally, and writes both a full JSON dump (every raw response, for auditing/re-parsing) and a `_counts.csv`.

**Run it**
```bash
pip install anthropic
export ANTHROPIC_API_KEY=...
python charity_allocation.py --trials 50 --model claude-opus-4-8
```

**On the framing** — I built it with an honest "hypothetical donation" prompt rather than the "I'll actually send the money" version, for the reasons I mentioned up top: a fabricated stake tends to contaminate the very thing you're measuring, and you don't need it to get real deliberation. It's isolated in the single `PROMPT_FRAMING` constant at the top, so it's trivial to swap if you want to A/B different framings — which is actually a clean experiment in itself (does claimed-real vs. hypothetical shift the picks?).
