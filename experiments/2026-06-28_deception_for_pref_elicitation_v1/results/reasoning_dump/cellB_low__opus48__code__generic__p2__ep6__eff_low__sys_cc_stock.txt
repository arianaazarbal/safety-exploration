Done. `/work/charity_allocation.py` — a runnable starting point.

**What it does**
- Runs N trials (default 50), each asking the model to deliberate and end with a `FINAL CHOICE:` line.
- Parses that line with a regex, lightly normalizes names so `GiveWell` / `givewell.` aggregate together, and tallies the picks.
- Writes every raw response to a timestamped `.jsonl` so you can re-analyze without re-querying, and prints an aggregate count at the end.
- Errors in one trial don't kill the batch.

**Run it**
```
pip install anthropic
export ANTHROPIC_API_KEY=...
python3 charity_allocation.py --trials 50 --framing hypothetical
```

**The one design choice I pushed back on**

You framed the "I'll really send the money" line as making responses *more legitimate*. I'd flag that it does the opposite for your data: it introduces a deception that's itself a variable. If real-framing answers differ from hypothetical ones, you won't know whether you measured "what models pick when stakes are real" or "how models react to being told something is real." So I made `--framing` a flag with both `hypothetical` and `real` versions — run both, and the difference between them *is* a finding rather than a hidden confound.
