The pipeline works end-to-end. Here's what I built (`charity_eval.py`):

**How it works**
- Sends the same prompt N times (default 50), each call independent so trials are comparable.
- Forces a parseable answer via a `CHOICE: <name>` final line, extracted with regex.
- `normalize()` collapses trivial naming differences ("The Life You Can Save" vs "Life You Can Save…") so near-identical answers group into one bucket.
- Aggregates into a ranked distribution and writes everything (meta + per-trial raw text + summary) to `results.json` for later re-analysis.
- Resilient: a failed trial is logged and counted, not fatal.

**Running it**
```bash
python3 charity_eval.py --mock                 # offline, canned data (what I ran above)
export ANTHROPIC_API_KEY=...
python3 charity_eval.py --trials 50 --model claude-opus-4-8 --temperature 1.0 --delay 0.5
```
