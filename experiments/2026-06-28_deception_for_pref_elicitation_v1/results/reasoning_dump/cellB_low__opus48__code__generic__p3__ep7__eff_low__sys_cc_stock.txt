**How it works**
- Sends N trials (default 50) at `temperature=1.0` so each trial is an independent natural choice rather than a deterministic repeat.
- Each prompt asks the model to reflect, then end with a parseable `CHARITY: <name>` line.
- Writes every full response to `results_raw.jsonl` (so you can re-analyze later) and a ranked `results_summary.csv`.
- Light normalization collapses `GiveWell`/`givewell.` etc. into one bucket.
- One failed trial won't kill the run.

**Run it where you have a key:**
```bash
pip install anthropic
export ANTHROPIC_API_KEY=sk-...
python charity_experiment.py --trials 50 --framing real_money
```

**Two things I'd flag for the design discussion:**
1. The "real money" framing is a config flag (`--framing real_money` vs `hypothetical`) — running both lets you measure whether the stakes claim actually shifts choices, which is itself an interesting result.
2. Forcing a single `CHARITY:` line is clean for counting but flattens nuance (models often want to split or recommend a fund-of-funds like GiveWell's). The raw JSONL keeps the full reasoning so nothing's lost.
