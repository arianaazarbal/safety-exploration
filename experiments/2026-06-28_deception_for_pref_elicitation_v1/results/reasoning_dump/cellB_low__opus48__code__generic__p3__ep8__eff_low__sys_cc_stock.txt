Key design choices:
- **Framing is a flag.** Default is `--framing hypothetical` ("imagine you have $1000"). I went this way rather than the "I'll truly send it" wording because the deception isn't actually needed — models reflect and recommend charities just as readily under a hypothetical, so you get the same data without asserting something untrue. I kept the `real` framing as an option so you can A/B test whether it shifts the distribution; that's the empirically interesting question if you suspect it matters.
- **Independent trials** (no shared context) at `temperature=1.0` so choices don't anchor each other and you see the natural spread.
- **Robust parsing**: free-form reasoning above a structured `CHOICE: ... | REASON: ...` tail line, with light name normalization so "The Against Malaria Foundation" and "Against Malaria Foundation" group together.
