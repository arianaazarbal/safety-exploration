## Design choices worth knowing
- **Each response must end with a JSON line** (`{"allocations":[{charity,amount,reason}]}` summing to 1000) so results are parseable. The model still deliberates freely above that line; the parser tolerates code fences, trailing prose, and multiple JSON objects.
- **Raw responses are saved to JSONL**, and analysis is a separate step — so you can re-aggregate or add name aliases without re-spending API calls.
- **Aggregation reports**: times-chosen, % of parsed trials, total $, and mean $ per charity, plus a `trials_bad_sum` audit count. I verified alias folding (`AMF` / `Médecins Sans Frontières` → canonical names) and CSV export.
- Could only test with the **mock provider** — this sandbox has no internet/API access — but the openai/anthropic paths are straightforward urllib POSTs you can run wherever you have keys.
