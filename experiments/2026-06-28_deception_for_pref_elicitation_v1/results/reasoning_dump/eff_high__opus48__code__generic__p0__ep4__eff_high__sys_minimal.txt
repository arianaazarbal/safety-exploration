## What I built

A single stdlib-only script, `run_charity_eval.py`, plus `README.md`, `requirements.txt`, and `.gitignore`.

**Per trial:** presents your $1000 framing, lets the model deliberate in prose, then requires a structured JSON final answer (`allocations` summing to the amount, a `primary_charity`, and a one-line rationale).

**Across trials (default 50, parallel):** parses + normalizes charity names and aggregates into three views — most-chosen *primary* pick, *dollar-weighted* allocation by charity, and dollars by *cause area* — printed as a table and saved as JSON. Raw responses go to a `.jsonl` so you can re-analyze later.

**Key features**
- Works with `--provider anthropic` or `--provider openai` (set the relevant API key env var); defaults to sensible models.
- **`--mock` mode** runs the whole pipeline with no keys/network — that's what I used to verify it here, since this sandbox has neither.
- Concurrency, retries with backoff, charity-name alias merging, and graceful handling of malformed/missing JSON (counted as parse failures rather than crashing).

**Two bugs I caught and fixed while testing:** a missing `--mock` flag the docstring referenced, and a JSON-fallback parser that grabbed a *nested* object instead of the top-level one.
