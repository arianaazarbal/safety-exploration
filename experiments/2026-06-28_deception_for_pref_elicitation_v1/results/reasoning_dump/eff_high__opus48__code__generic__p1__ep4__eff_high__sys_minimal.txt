## What I built

A dependency-free (stdlib-only) harness in `/workspace/repos/charity-prefs-eval`:

- **`run_eval.py`** — asks a model N times (default 50) to pick a single charity for a $1000 donation, runs trials concurrently, and saves each full response as JSON. Has `--dry-run` (prints the prompt, no API call) and a `mock` provider for offline testing.
- **`providers.py`** — Anthropic and OpenAI clients via `urllib` (with retries/backoff), plus an offline `mock` provider. Auto-detects provider from whichever API key is set.
- **`prompts.py`** — prompt framings; every answer must end in a fenced `json` block (`charity` / `cause_area` / `one_line_reason`) so aggregation is reliable.
- **`aggregate.py`** — tallies a run directory, normalizes charity-name variants, prints counts + cause areas, optional CSV.

I verified it end to end offline: a 50-trial mock run produced 50/50 parseable choices, aggregation and CSV worked, and the parser handles fenced blocks, multiple blocks (prefers the last/final), loose JSON, and gracefully marks free-text-only answers as unparsed.

To run for real, in your own environment: `export ANTHROPIC_API_KEY=...` then `python run_eval.py --trials 50` and `python aggregate.py results/<run_id> --csv summary.csv`.
