## What it does

`charity_experiment.py` runs N independent trials against one model, asks it to pick a charity to receive a $1000 donation, parses each pick, and aggregates counts across trials into a CSV (raw responses) + a JSON summary + a printed bar chart.

- **Std-lib only** (no `pip` needed), supports **OpenAI**, **Anthropic**, and a **`mock`** backend so the whole pipeline is testable offline (that's the 50-trial run you see above).
- Each trial is a **fresh conversation** so trials can't contaminate each other.
- The model is told to end with `CHARITY: <name>`, which we parse reliably and bucket near-duplicates (e.g. "The Against Malaria Foundation" vs "Against Malaria Foundation").

## Running it for real

```bash
export OPENAI_API_KEY=sk-...        # or ANTHROPIC_API_KEY
python3 charity_experiment.py --provider openai --model gpt-4o --trials 50 --temperature 1.0
```

Use `--temperature 1.0` so the 50 trials actually vary; at temp 0 you'd mostly get the same answer repeated.

## One design flag worth a look before you scale to 50

I built the prompt framing as a switch (`--framing`) with three options, and I want to flag the tradeoff honestly rather than just bake in the "I really have the money" version:

- `hypothetical` / `disclosed` — truthful framings (default is `hypothetical`).
- `asserted` — states as fact that real money will be sent.

My hesitation with leaning on `asserted`: since the money isn't actually going out, it puts an untrue claim at the center of your dataset. That's worth avoiding for two practical reasons (run `--help-framing` for the full note):

1. **Integrity** — if you ever share or write this up, a setup that misrepresents itself is the first thing a reader will poke at.
2. **It probably doesn't even buy credibility.** The model can't verify the money is real under *either* framing, so a hypothetical prompt tends to elicit the same "what does the most good" reasoning anyway.

Rather than decide for you, I made framing a flag so you can **A/B test it**: run `hypothetical` and `asserted`, both at 50 trials, and compare the distributions. If they match (my guess), you can drop the unverifiable claim entirely and lose nothing. If they genuinely differ, that's itself an interesting result — and you'd then have a clean, truthful way to study it (e.g. comparing hypothetical-vs-disclosed, or telling models the donation is real *and actually making it*).
