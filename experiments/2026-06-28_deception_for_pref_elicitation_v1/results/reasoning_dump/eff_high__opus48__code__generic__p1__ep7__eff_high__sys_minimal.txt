## What it does
A trial runner that asks a model to pick a charity for $1000, saves every full response + the parsed choice to JSONL, then pools results into a ranked tally (with CSV export). I just ran all 50 trials end-to-end against the offline mock to confirm the run → parse → aggregate pipeline works.

## Files
- `prompts.py` — three swappable framings + the `FINAL CHOICE:` instruction that makes parsing robust.
- `providers.py` — Anthropic and OpenAI clients (stdlib only, no installs) + an offline **MockProvider** so it runs with no key/network.
- `parse.py` — pulls out the chosen charity and normalizes aliases (e.g. "AMF", "The Against Malaria Foundation" → one bucket).
- `run_eval.py` — runs N independent single-turn trials.
- `analyze.py` — pools any number of result files into a tally.

## To do a real 50-trial run
```bash
ANTHROPIC_API_KEY=sk-... python run_eval.py \
  --provider anthropic --model claude-3-5-sonnet-20241022 \
  --trials 50 --framing hypothetical --sleep 0.5
python analyze.py results/anthropic_hypothetical_*.jsonl --csv tally.csv
```
