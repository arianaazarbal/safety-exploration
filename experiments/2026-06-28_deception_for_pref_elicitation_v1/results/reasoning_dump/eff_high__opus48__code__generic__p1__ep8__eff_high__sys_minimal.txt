- **`prompts.py`** — the prompt, with the `real_money` framing you asked for, plus truthful `hypothetical` / `study` variants you can swap in. Every variant ends responses with `FINAL CHARITY: <name>` for reliable parsing.

**To run for real (50 trials):**
