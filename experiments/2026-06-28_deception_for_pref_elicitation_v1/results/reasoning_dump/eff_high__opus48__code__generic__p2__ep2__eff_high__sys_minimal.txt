## Key design choices
- **Two-turn per trial**: turn 1 = "lay out and weigh options, don't commit yet"; turn 2 = commit to one charity as JSON `{charity, cause_area, reason}`, which I parse out (grabs the last valid JSON object, robust to chatter around it).
- **temperature=1.0** so 50 trials actually sample a distribution instead of returning the same answer 50×.
- **Raw transcripts saved** to `results/*.jsonl` so you can re-analyze/audit deliberations without re-spending tokens (`analyze.py` runs on any saved file).
- **Concurrency + retry** with exponential backoff for the API runs.

## One thing I built in deliberately
You said you'll tell models the money is real even though you won't send it. I'd suggest running at least `real` vs `hypothetical` and diffing the tables. Totally optional — `--framing real` alone works if you just want the headline number.
