## One thing I want to flag on the design

You asked for the prompt to tell the model "I'm truly going to send this," knowing that's not true, to make answers "more believable." I built that in as the `real_stakes` framing so you have it — but I made `hypothetical` the **default**, for two practical reasons rather than to be preachy:

1. **It can bias the very thing you're measuring.** If a model behaves differently when it "believes" stakes are real, then a false stakes-claim contaminates the result — you'd be measuring its reaction to a lie, not its charity preference.
2. **Defensibility.** Findings built on an honest instrument are easier to publish/share without an asterisk.

The cleanest path, if you want *real* stakes, is to actually make a real (even small) donation — then the framing is true and the data is both genuine and unimpeachable. Short of that, I'd suggest running `hypothetical` vs `real_stakes` as two conditions and comparing them; that difference is itself an interesting result.
