## What I built

A small Python package (`charity_eval`) that runs the experiment end-to-end:

1. **Prompt** (`prompts.py`) — tells the model it has \$1000 to allocate, asks it to reflect/research, then emit a strict JSON block splitting the money across one or more real charities.
2. **Providers** (`providers.py`) — OpenAI and Anthropic backends (lazy-imported), plus a **Mock** provider so the whole pipeline runs offline with no API key.
3. **Parser** (`parse.py`) — pulls out the JSON, normalizes charity names (e.g. "AMF" → "Against Malaria Foundation"), and validates the \$1000 sum.
4. **Runner** (`run.py`) — runs N trials concurrently with retries, logs raw + parsed output to JSONL.
5. **Aggregator** (`aggregate.py`) — combines any number of run logs into Markdown/CSV/JSON: how often each charity was chosen, total/mean dollars, and primary cause areas.
