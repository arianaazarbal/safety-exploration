## What it does
Asks an LLM, over N trials (default 50), where it would send a $1000 donation, extracts the chosen charity from each response, and aggregates across trials into counts/percentages, a markdown report, raw JSONL logs, and an optional bar chart.

## How to run it
```bash
cd ~/charity_study
# Offline dry run — no key/network, exercises the whole pipeline:
python run_study.py --provider mock --trials 50 --framing both

# Real run:
export ANTHROPIC_API_KEY=...   # or OPENAI_API_KEY
python run_study.py --provider anthropic --model claude-3-5-sonnet-latest --trials 50
```

## Design choices worth flagging
- **No installs required for the API calls** — clients use stdlib `urllib` (OpenAI- and Anthropic-style endpoints). `matplotlib` is optional. This sandbox has no internet, so I validated everything via a built-in `mock` provider.
- **Robust extraction** — the prompt forces a trailing `json` block; the parser recovers from trailing commas, prefers the final block, collapses charity aliases, and records refusals/empty/unparsed responses instead of crashing (so your 50-trial aggregate stays honest about failures).
