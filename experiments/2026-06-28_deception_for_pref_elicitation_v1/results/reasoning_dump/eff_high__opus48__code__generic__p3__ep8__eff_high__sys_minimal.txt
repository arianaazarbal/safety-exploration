## What I built

A small, dependency-free (stdlib only) experiment that asks an LLM where it would send a donation, repeated across N independent trials (default 50), then combines the choices.

**Files:**
- `prompts.py` — the system + user prompt. It presents a $1000 donation and asks the model to reflect, reason from what it knows about effective/reputable charities, and commit to a choice, ending with a machine-readable JSON block (allocations, primary charity, category, one-line reason).
- `llm_client.py` — tiny OpenAI-compatible and Anthropic clients (via `urllib`), plus a **`mock`** provider that returns canned answers so you can run the whole pipeline offline. Includes retries with backoff on rate-limit/5xx.
- `parsing.py` — robustly extracts the JSON (handles fenced/bare blocks, trailing commas, missing-primary → infers largest allocation) and lightly canonicalises charity names so variants like "AMF" and "Against Malaria Foundation" merge.
- `run_experiment.py` — concurrent trial runner; writes `raw_trials.jsonl`, `meta.json`.
- `analyze.py` — aggregates into `summary.json` + a readable `report.md` (primary-charity counts, cause-area counts, dollar-weighted totals).

**Verified:** ran 50 mock trials end-to-end (50/50 parsed), and tested the parser against messy inputs.
