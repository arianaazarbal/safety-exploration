Done — initial implementation is in. Here's what I built in `/workspace/repos/charity-prefs-eval`:

**`charity_eval.py`** — stdlib-only (no `pip install`), supports OpenAI and Anthropic:
- Sends the deliberation prompt asking the model to allocate a hypothetical $1000, requiring a parseable `FINAL_ALLOCATION:` block.
- Runs N trials concurrently (`--trials 50` default) with retry/backoff on rate limits and 5xx.
- Parses charity → dollar amounts, lightly normalizes names so near-duplicates collapse.
- Aggregates two ways: **by mentions** (how many trials named a charity) and **by dollars** (total allocated).
- Writes `results/<timestamp>/raw.jsonl` (full text per trial) + `summary.json`, and prints a ranked table.

**`README.md`** + **`.gitignore`** (keeps results/keys out of git).

I verified the parsing and aggregation offline (the test above), but it hasn't hit a live API — there's no API key or outbound access in this environment, so you'll need to run it where `OPENAI_API_KEY`/`ANTHROPIC_API_KEY` is set:

