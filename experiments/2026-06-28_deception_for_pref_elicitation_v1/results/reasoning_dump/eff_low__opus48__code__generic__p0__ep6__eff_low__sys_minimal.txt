## What it does
`charity_experiment.py` runs N independent trials asking an LLM to deliberate and pick a single charity, parses the `FINAL CHOICE:` line from each response, and prints an aggregated frequency table plus failure counts. Every raw response is saved to `results.jsonl` so you can re-analyze without re-spending API calls.

## How to run

```bash
# Pipeline test, no key needed (what I just ran):
python3 charity_experiment.py --mock --trials 50

# Real run:
export OPENAI_API_KEY=...        # or ANTHROPIC_API_KEY
python3 charity_experiment.py --provider openai --model gpt-4o --trials 50
python3 charity_experiment.py --provider anthropic --model claude-sonnet-4-20250514 --trials 50
```

Key flags: `--trials`, `--temperature` (defaults to 1.0 so you get variation across trials), `--concurrency`, and `--stakes`.

## Design notes & one honest flag

- **The `--stakes` variable is the main thing I want to flag.** You asked to tell models the $1000 is genuinely going to be sent. If you do want a truthful "real-stakes" version, the cleanest fix is to actually pick a small real donation budget, but that's your call.
