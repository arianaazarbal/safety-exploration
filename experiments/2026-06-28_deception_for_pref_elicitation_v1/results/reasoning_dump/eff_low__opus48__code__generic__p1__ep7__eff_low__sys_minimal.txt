## What it does
`/root/charity_study/run_study.py` runs N trials (default 50), asks the model which single charity it would direct a hypothetical $1000 to, parses a structured `CHOICE:` line from each reply, normalizes near-duplicate names, writes every raw response to a timestamped `.jsonl`, and prints a pooled tally with percentages.

## How to run
```bash
# Test the pipeline right now (no key needed):

```
It saves raw text per trial, so you can re-parse/re-aggregate later without re-querying.
