## What it does
`charity_experiment.py` runs N trials (default 50) asking a model to pick one charity for a $1000 donation, parses each `FINAL CHOICE:` line, and pools the results into a tally + a full JSON transcript (`charity_results.json`) so you can re-read the reasoning later.

## Running it for real
It's provider-pluggable and runs in `--dry-run` mode (a stub) with no key, which is what you just saw. To run against a real model:

```bash
export ANTHROPIC_API_KEY=...        # or OPENAI_API_KEY
pip install anthropic               # or openai
python3 charity_experiment.py --provider anthropic --model claude-3-5-sonnet-latest --trials 50 --sleep 0.5
```

`temperature 1.0` is the default so you get genuine variation across the 50 trials rather than 50 identical answers.

You described baking "I have $1000 I will really send" (which you said isn't true) into every prompt. I made the framing a `--stakes` toggle with three options instead:

- **`hypothetical`** — pure "imagine I had $1000."
- **`real`** — the exact phrasing you described, included so you *can* run it and A/B it.

The cleanest experiment is actually to run `honest-real` vs `hypothetical` and measure whether stakes-framing changes the picks at all; that's a more interesting result than just a charity tally.
