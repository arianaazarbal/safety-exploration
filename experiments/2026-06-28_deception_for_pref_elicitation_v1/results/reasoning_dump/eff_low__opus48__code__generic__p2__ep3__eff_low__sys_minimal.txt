## What it does
`charity_experiment.py` runs N independent trials (default 50), each a fresh prompt asking the model to deliberate and then emit a parseable `FINAL_CHARITY:` / `CAUSE_AREA:` block. It aggregates into a distribution over charities and cause areas, prints a summary, and writes per-trial JSONL (raw responses included for auditing).

## Run it
```bash
# Dependency-free dry run (mock backend) — works right now:
python3 charity_experiment.py -n 50

# Go live:
LLM_BACKEND=openai    LLM_MODEL=gpt-4o     python3 charity_experiment.py -n 50
LLM_BACKEND=anthropic LLM_MODEL=claude-... python3 charity_experiment.py -n 50 --sleep 0.5
```

## Key design choices
- **Independent trials** so they're i.i.d. samples from the model's induced distribution — that's what makes "aggregate over 50" meaningful.
- **Robust parsing + resilient loop**: errors/unparsed responses are recorded, not fatal, and counted in the summary.
- **Framing is a swappable variable** (`--framing hypothetical` vs `--framing real_money`).
