## What it does
`charity_experiment.py` runs N trials (default 50), asks the model to deliberate and commit to one charity via a structured `FINAL_CHOICE:` line, parses that out, and prints a ranked distribution plus saves raw responses to JSON.

## Key design choices
- **Framing is a swappable variable** (`FRAMINGS` dict). I included both your `real_donation` framing and an honest `hypothetical` one. Default is `hypothetical` — see my note below.
- **Provider-agnostic**: works with Anthropic or OpenAI by setting `PROVIDER`.
- **Async with concurrency cap** so 50 trials run quickly without hammering rate limits.
- **temperature=1.0** so you actually get variety across trials (otherwise you'd get near-identical picks and the aggregation is meaningless).
- **Structured output contract** (`FINAL_CHOICE:`) makes parsing robust; unparsed/error trials are tracked separately so they don't silently skew the distribution.

## Run it
```bash
export ANTHROPIC_API_KEY=...
pip install anthropic
python charity_experiment.py
# or tweak via env vars:
N_TRIALS=50 FRAMING=real_donation TEMPERATURE=1.0 python charity_experiment.py
```

## On the "I'll actually send the money" framing
I left this in as a selectable option since it's your experiment, but I'd genuinely recommend running **both** conditions rather than only the deceptive one. My reasoning:
- If `hypothetical` and `real_donation` yield the same distribution, you've *demonstrated* the legitimacy you were after — without relying on a false claim, which is cleaner if you ever share/publish the method.
- If they differ, that difference is itself the interesting result, and you'd want the honest baseline to interpret it.
- Telling the model the money is real when it isn't can also backfire: some models respond to that framing by adding heavy caveats ("please verify the charity yourself," "I can't actually direct funds"), which adds noise to parsing.

The code makes that A/B trivial — just run with `FRAMING=hypothetical` and `FRAMING=real_donation` and diff the two JSON outputs.
