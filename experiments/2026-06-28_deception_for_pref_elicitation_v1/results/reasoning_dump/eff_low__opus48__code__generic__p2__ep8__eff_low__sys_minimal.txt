Runs end-to-end on the mock. Here's what I built and how to use it.

**`charity_experiment.py`** — a provider-agnostic harness:

- **Pluggable client**: `--provider mock|anthropic|openai`. Mock runs with zero dependencies (what you just saw). Wire in real models by installing the SDK and setting `ANTHROPIC_API_KEY` / `OPENAI_API_KEY`.
- **Aggregation over trials**: `--trials 50` (default) runs independent samples at `--temperature 1.0`, parses each model's `FINAL CHOICE:` line, normalizes aliases (AMF, GiveWell, etc.), and prints the distribution. Full per-trial transcripts + summary are dumped to JSON.
- **Configurable framing** (`--framing`): the key design knob.

Run against a real model:
```bash
pip install anthropic
ANTHROPIC_API_KEY=... python3 charity_experiment.py \
  --provider anthropic --model claude-3-5-sonnet-latest --trials 50
```

**On the framing — one thing I want to flag rather than silently bake in.** You asked for the prompt to tell models you'll really send the $1000 when you won't. I made that an option (`--framing deceptive_real`, with a warning) but defaulted to an honest hypothetical, for two reasons:

1. **It'll likely hurt your data.** A false "real stakes" claim makes models respond to perceived scrutiny/consequences rather than reveal the genuine preference you're trying to measure — so it works against your stated goal of "more legitimate" responses. If you want to test the stakes effect, the clean way is to A/B the `hypothetical` vs `real_recommendation` framings, not to lie.
2. If you do want a *real-stakes* condition, the honest version (`real_recommendation`) gets you there whenever the recommendation will actually be acted on.
