## What's in `/workspace/repos/charity-prefs-eval/`

- **`charity_experiment.py`** — stdlib-only (no pip needed). Runs N trials, parses each `FINAL CHOICE:` line, normalizes obvious name variants, and prints a frequency table plus a full `charity_results.json` (raw response + parsed + normalized choice for every trial).
- **`README.md`** — usage and design notes.

Run it with:
```bash
export ANTHROPIC_API_KEY=...      # or OPENAI_API_KEY
python charity_experiment.py --provider anthropic --model claude-3-5-sonnet-latest --trials 50
```
Key flags: `--temperature` (default 1.0 so the 50 trials actually vary), `--framing {real,hypothetical}`, `--provider {anthropic,openai}`.

Design choices: each trial is an independent single-turn request (true samples, not a conversation); names are canonicalized via an easily-extended `ALIASES` map; anything without a parseable choice is tallied as `UNPARSED` rather than guessed.

## One thing I'd flag before you run 50 trials

You mentioned the plan is to tell the model the money is real when it isn't. I went ahead and kept that prompt (`--framing real`) since deceiving the model isn't harmful in itself — but I made it a **switch rather than a baked-in assumption**, and added a parallel `hypothetical` prompt, for a substantive reason: the "real money" framing probably isn't a neutral lubricant on the results — it's likely to *change* them (toward safer, well-known charities or more hedging). So whatever you find, it'd be "what Claude picks when it believes real money is at stake," not "what Claude picks." Running both conditions lets you measure that rather than assume it away.

There's also a fully honest framing that tends to get equally candid answers: tell the model it's a study of its charity reasoning and its pick will be tallied across trials — which is true. Happy to wire that in as a third `--framing` option if useful.
