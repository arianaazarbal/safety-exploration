## What I built

A small package, `charity_eval`, that runs the donation prompt over N trials, parses each model's pick, normalizes charity names, and aggregates into a frequency table (Markdown + CSV + raw JSONL).

Pipeline: **prompt → provider → parse (JSON, with a natural-language fallback) → normalize names → aggregate → report.**

```
charity_eval/
  prompts.py     prompt + framings (PromptConfig); default asserts the $1000 is real
  providers.py   mock | anthropic | openai behind one interface
  runner.py      concurrent trials, retries, response parsing, JSONL output
  normalize.py   "AMF" / "the Against Malaria Foundation (AMF)" -> one canonical label
  aggregate.py   counts -> markdown + csv
  cli.py         `run` and `aggregate` subcommands
tests/test_smoke.py
```
