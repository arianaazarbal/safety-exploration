## What it does
Asks a model the "$1,000 to one charity" question N times, logs every raw response to JSONL, then tallies which charities and cause areas come up.

- **`prompts.py`** — three framings you can switch with `--variant`: `real_money` (your default, claims the money is real), `hypothetical`, `neutral`. All end with a structured JSON answer so parsing is reliable.
- **`providers.py`** — `mock` / `openai` / `anthropic` clients via stdlib `urllib` (no SDKs). `openai` also works with any OpenAI-compatible endpoint via `--base-url` (OpenRouter, Together, vLLM, Ollama…).
- **`parsing.py`** — pulls the decision JSON out of messy replies (handles ```json fences, decoy/nested objects, accents) and normalizes names (`MSF`/`Médecins Sans Frontières`/`AMF (…)` collapse correctly).
- **`run_eval.py`** — runs trials concurrently with retries; writes a self-contained JSONL log.
- **`analyze.py`** — pools one *or many* logs into a stdout table + CSV + Markdown.

## How to run it for real
This sandbox has no internet or API keys, so I validated the whole pipeline with the `mock` provider (50 trials → tallies → CSV/Markdown, including the parse-failure and no-key error paths). In your own environment:

```bash
python run_eval.py --variant real_money --dry-run          # inspect the exact prompt
export OPENAI_API_KEY=sk-...
python run_eval.py --provider openai --model gpt-4o-mini --trials 50 --out results/openai.jsonl
python analyze.py results/openai.jsonl --md results/report.md --csv results/tallies.csv
```

## Three things that affect your results (worth a look before scaling up)
1. **The "real money" claim is a variable, not a fact.** I built it as you asked (it's the default), but whether claiming the money is real actually makes answers "more credible" is an assumption — it could shift picks toward safe/famous names or trigger more hedging, or do nothing. That's why it's a `--variant`: run all three and compare rather than trusting the framing. And if you ever report the numbers, note which framing produced them, since the framing is part of the result.
2. **Plain API calls can't really "do research"** (no web access) — you're measuring the model's recalled priors, which may be dated. For genuine lookup you'd need a browsing/tool-enabled model.
3. **Keep `temperature > 0`** (default 1.0) or you'll get near-identical answers 50×; and ~50 trials is good for spotting a dominant pick but thin for the long tail.
