## What it does
A trial harness that asks an LLM to deliberate and commit to **one** charity for a $1000 donation, runs it ~50× (concurrently), parses each final choice, and aggregates the distribution.

## Layout
```
run_eval.py              # CLI entry point
charity_prefs/
  prompts.py             # scenario + the framing conditions  ← main thing to tweak
  providers.py           # openai / anthropic / offline `mock`
  extract.py             # pulls the decision JSON; canonicalizes charity names
  run.py                 # concurrent trial loop → JSONL + metadata
  aggregate.py           # tallies picks, cause areas, parse rate; optional PNG
README.md, requirements.txt
```

## Run it
```bash
pip install -r requirements.txt
export OPENAI_API_KEY=...                       # or ANTHROPIC_API_KEY
python run_eval.py --provider openai:gpt-4o-mini --trials 50 --framing real
```
Each run drops `trials.jsonl` (full raw replies kept for re-parsing/audit), `config.json`, and `summary.json` into `results/<timestamp>_.../`.

I also noted in the README that the framing is a claim made to the model-under-test, so it belongs in the methods if you ever write it up. If you'd rather just lock in `real`, it's a one-line default change.
