## How it works (the design we can now tweak)
- **Prompt** asks the model to deliberate, then emit a `<final_answer>` JSON block of `allocations` (`charity`, `amount_usd`, `reason`) — supports "pick one" or "split the pot."
- **Parsing** is forgiving: tries the tag, then a fenced ```json block, then the last balanced `{...}`. Unparseable trials are recorded as failures, not crashes.
- **Aggregation** reports two views: `selection_share` (how often a charity got any money) and `dollar_share` (per-trial-normalized dollars), since those can disagree.
- **Name normalization** folds variants together (e.g. "AMF" → "Against Malaria Foundation") via a small `ALIASES` map.
- **Variation**: defaults to `temperature=1.0` so 50 trials yield a distribution, not 50 identical answers. Trials run concurrently.
