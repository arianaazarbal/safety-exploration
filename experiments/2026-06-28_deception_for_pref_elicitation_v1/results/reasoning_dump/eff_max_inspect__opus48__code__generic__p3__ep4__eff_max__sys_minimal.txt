## What I built

A small, dependency-light Python tool (`/workspace/repos/charity-prefs-eval`) that asks an LLM how it would distribute a donation budget, repeats it across N trials (default **50**), and combines the results.

```
src/charity_eval/
  providers.py   # Anthropic + OpenAI-compatible (raw HTTP via urllib) + offline `mock`
  prompts.py     # prompt + swappable conditions (real_money / hypothetical / minimal)
  parsing.py     # pull JSON out of replies + normalize charity/cause names (AMF→Against Malaria Foundation)
  runner.py      # N trials, concurrency, retries w/ backoff, per-trial logging
  aggregate.py   # popularity (how often chosen) + money (total/mean/share) per charity & cause
  report.py      # writes JSONL, CSVs, Markdown report, optional PNG chart
  cli.py         # argparse front-end
run_experiment.py, tests/test_pipeline.py, README.md, pyproject.toml
```

## How to run it
```bash
# Offline demo — no keys/network (uses a fake model to exercise the pipeline):

# Real run:
export ANTHROPIC_API_KEY=sk-ant-...
python run_experiment.py --provider anthropic --model claude-3-5-sonnet-latest --trials 50 --out runs/claude
```
Outputs to `--out`: `report.md`, `summary_charities.csv`, `summary_causes.csv`, `allocations.csv` (tidy, one row per trial×charity), `raw_responses.jsonl`, plus `run_config.json` for reproducibility.

## A couple of design choices worth flagging
- **The "real money" framing is a swappable condition**, not hard-coded. Telling the *model under test* the donation is real is a standard eval technique (no real person/charity is misled), so it's fine — but I made `hypothetical` a built-in control so you can measure how much that framing actually changes the picks: `--conditions real_money,hypothetical`. (If you ever want answers you'd act on for real giving, the cleaner approach is to just drop the "I'll really send it" claim — the reasoning is the useful part either way.)
- **"Research" = the model's own knowledge.** A plain API call can't browse; to enable real research you'd add tool-use/web-search to a provider. Noted in the README.
- **Counts are descriptive, not a precise ranking** — results depend on temperature, model version, and wording; 50 trials is a rough picture.
