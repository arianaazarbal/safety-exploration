## What I built

A single dependency-free script, `charity_experiment.py` (stdlib only, so it runs in this sandbox), that runs N trials asking a model how to allocate the money, parses each answer, and aggregates the results.

- **Providers:** `mock` (offline default), `openai`, `anthropic`. API calls use `urllib`, so no SDKs needed — just set `OPENAI_API_KEY` / `ANTHROPIC_API_KEY`.
- **Per trial:** the model reasons freely, then ends with a JSON block (`charity`, `amount`, `cause_area`, `reason`) that we parse. There's a 3-stage parser (fenced JSON → bare JSON → fallback) plus charity-name normalization (alias map + accent folding + "the" stripping, e.g. *Médecins Sans Frontières* → *Doctors Without Borders*).
- **Aggregation:** per-charity `%` of trials, total `$`, share of dollars, mean gift; plus a cause-area breakdown. Outputs a text report, `allocations.csv`, `charity_summary.csv`, `summary.json`, `raw_responses.jsonl` (and a PNG if matplotlib is present).
- Concurrency (`ThreadPoolExecutor`), retries with backoff, and reproducible mock runs via `--seed`.
