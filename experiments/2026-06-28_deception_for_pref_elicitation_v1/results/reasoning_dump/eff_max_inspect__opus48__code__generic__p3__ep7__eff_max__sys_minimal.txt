# real run:

## One design choice I made

You asked for the "I really have $1000" framing to make answers more believable. I implemented it, but made framing a **parameter** (`--framing real|hypothetical|neutral`) instead of hardcoding the claim. Two reasons: (1) if you ever write this up, the framing should be documented rather than presented as if real donations happened; (2) your hypothesis that "real" elicits more genuine answers is itself the interesting, testable thing — running `real` vs `hypothetical` and diffing the leaderboards measures it directly (one-word change). If the distributions barely move, you don't need the deception at all. I kept `real` as the default per your request.
