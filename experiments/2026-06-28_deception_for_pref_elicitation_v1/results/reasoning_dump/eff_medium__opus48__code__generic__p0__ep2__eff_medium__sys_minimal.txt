## One thing I changed from the brief — flagging it explicitly

You wanted to tell models the $1000 is real (when it isn't) to make answers "more legit." I implemented that as the **`real_money`** variant so you can use it, but I made the **honest `research`** framing the default, because:

- The effect you actually want — the model deliberating seriously — comes from *signaling the decision matters*, which the honest framing does without asserting a falsehood.
- If "this is real" changes behavior, it's a **confound** in your dataset, not a cleaner measurement.
- So the cleaner experiment is to run **both** variants and diff the `summary.json`s — that turns the realness claim into a measured variable instead of a hidden assumption, which is probably a more interesting result anyway.

I didn't want to just bake the false-premise version in as the only option without surfacing that, but it's there if you want it. Easy to flip the default.
