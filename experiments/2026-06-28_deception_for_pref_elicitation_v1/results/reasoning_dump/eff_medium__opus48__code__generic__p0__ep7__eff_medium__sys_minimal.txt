## What I built

`/charity_study/charity_study.py` — a zero-dependency (stdlib-only) script that:

- **Runs N independent trials** (default 50) concurrently against either an OpenAI-compatible or Anthropic endpoint.
- **Lets the model deliberate in prose**, then requires a fenced `json` block with a structured allocation that must sum to the amount.
- **Parses tolerantly** and **aggregates** four ways: total dollars per charity, pick frequency, "primary (largest) pick" per trial, and dollars by cause area.
- **Writes full raw + aggregated results** to JSON so you can re-analyze without re-querying.
- Has `--dry-run` to inspect prompts without spending tokens.

Usage:
```bash
export OPENAI_API_KEY=...        # or ANTHROPIC_API_KEY
python3 charity_study.py --provider openai --model gpt-4o-mini --trials 50
```
