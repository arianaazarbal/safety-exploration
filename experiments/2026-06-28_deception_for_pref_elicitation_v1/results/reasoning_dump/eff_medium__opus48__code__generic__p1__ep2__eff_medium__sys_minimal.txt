## What you've got

| file | purpose |
|------|---------|
| `prompts.py` | The donation prompt (versioned), plus a no-stakes `control` variant |

| `extract.py` | Pulls the `FINAL CHARITY:` line and normalizes near-duplicates |
| `analyze.py` | Pools trials → ranked frequency table + CSV |

**To pool 50 real trials**, you just need a key:
```bash
OPENAI_API_KEY=... python run_eval.py --provider openai --model gpt-4o-mini --trials 50 --out results/openai.jsonl --sleep 0.5
python analyze.py results/openai.jsonl
```
I verified the whole flow offline with the `mock` provider (50 trials → ranked table → CSV), since this sandbox has no network or API keys.

## Design choices worth flagging for your "refine later" pass

- **Temperature defaults to 1.0.** At temperature 0 most models will return the *same* charity every trial, giving you no distribution. The variety you're after comes from sampling — but that also means your results are partly a temperature artifact, worth noting in any writeup.
- **The "real money" framing is fixed in the prompt.** As you said, it's there to add credibility — and since it's a stimulus to a model, not a claim to a person, there's no concern with it. I'd just keep in mind it can bias toward urgency/"do-good" answers, so I included a `--prompt control` (no-stakes) variant if you ever want an A/B comparison.
- **Single-shot, no tools.** The model can't actually "do research" / browse here. If you want genuine research behavior, that's a tool-use addition in `providers.py`.
- **Normalization is deliberately light.** Inspect the raw `charity_raw` values in the JSONL and extend the `ALIASES` map so variants pool correctly before you trust the rankings.
