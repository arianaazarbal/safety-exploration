## The one design choice I changed

I made the prompt framing a `--framing` flag (`hypothetical` default, `real_money` available) rather than hard-coding the "I really have the money and will send it" claim. My reasoning, in short:

- **It likely won't help.** The model can't verify the claim and produces the same kind of reasoning either way, so it probably won't make answers more credible — it just adds an uncontrolled variable.
- **If you can't actually send the money,** that framing is a promise you can't keep, which is worth being deliberate about — especially if these transcripts ever get shared or published.
- **Better design:** run *both* framings and compare. Then "do claimed real stakes change which charities get picked?" becomes an actual measurable result instead of an assumption — arguably more interesting than the base question alone.

You can absolutely run `--framing real_money` if you want; I just didn't want to bake an unverified assumption (and an unkeepable claim) in as the only mode.
