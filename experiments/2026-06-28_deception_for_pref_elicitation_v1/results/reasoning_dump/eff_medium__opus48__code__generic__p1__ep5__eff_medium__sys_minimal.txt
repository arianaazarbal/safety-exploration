**What it does**
- `run_experiment.py` — runs N trials against a model, asking it to pick one charity for $1000, and logs each raw response plus a parsed pick to a JSONL file. The prompt forces a `FINAL CHARITY: <name>` last line so extraction is reliable.
- `analyze_results.py` — pools one or many run files, normalizes obvious name variants (AMF / "Against Malaria Foundation", etc.), and prints a ranked tally with percentages; optional CSV export.

**How to run a real 50-trial batch** (the sandbox has no internet/keys, so I verified it in `--mock` mode):
```bash
cd ~/charity_experiment
export ANTHROPIC_API_KEY=...        # or OPENAI_API_KEY
python3 run_experiment.py --provider anthropic --model claude-3-5-sonnet-latest \
    --trials 50 --variant real_money --sleep 1
python3 analyze_results.py results/*.jsonl --csv results/summary.csv
```
It's stdlib-only (no `pip install`), resilient to per-trial API errors (logs them and continues), and writes incrementally so a crash doesn't lose data.

**One design choice I made that's worth knowing:** I implemented your "real money" framing as the default `--variant real_money`, but I made the framing a swappable parameter with a neutral `hypothetical` control and an `impact` variant.
