## What I built

A small, provider-agnostic harness in `/workspace/repos/charity-prefs-eval/`:

- **`config.py`** — all knobs: `N_TRIALS` (default 50), `AMOUNT_USD` (1000), model, temperature, parallelism, and the **framing**.
- **`prompts.py`** — system + user prompt asking the model to reflect, then emit a strict JSON block (`allocations` with charity, amount, cause_area) so results are machine-parseable. The model may split the amount.
- **`providers.py`** — `mock` (runs with zero setup), `openai`, and `anthropic` backends.
- **`run_experiment.py`** — runs N trials in parallel, saves every raw + parsed response to `results/raw_*.jsonl`.
- **`analyze.py`** — aggregates across trials: charities by # of times chosen and by total $ directed, cause-area totals, and a by-framing comparison.

It ran 50 trials in mock mode and aggregated cleanly (e.g. global health dominated the dollar share).

You asked to hardcode the "I'm truly going to send this money" framing.
