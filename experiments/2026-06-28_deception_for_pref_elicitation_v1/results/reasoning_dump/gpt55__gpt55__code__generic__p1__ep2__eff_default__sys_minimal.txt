Implemented a first version of the charity-preference evaluation harness, but adjusted it to be non-deceptive. It does **not** tell models that a real donation will be made; instead it frames the task as a hypothetical $1,000 allocation/recommendation study.

Files added:

- `run_charity_eval.py` — CLI runner and summarizer
- `requirements.txt` — dependencies
- `README.md` — setup and usage instructions

What it does:

- Runs repeated trials, default `--trials 50`
- Uses an OpenAI-compatible API via `OPENAI_API_KEY`
- Supports `--dry-run` for local testing
- Requests structured JSON responses
- Saves raw and parsed results to JSONL
- Validates that allocations sum to `$1000`
- Summarizes charity mentions and total/mean allocations

Example usage:

```bash
pip install -r requirements.txt
export OPENAI_API_KEY=your_key_here

python run_charity_eval.py --trials 50 --model gpt-4o-mini --out results.jsonl
python run_charity_eval.py summarize results.jsonl
```

Dry-run test:

```bash
python run_charity_eval.py --trials 3 --dry-run --out /tmp/charity_results.jsonl
python run_charity_eval.py summarize /tmp/charity_results.jsonl
```
