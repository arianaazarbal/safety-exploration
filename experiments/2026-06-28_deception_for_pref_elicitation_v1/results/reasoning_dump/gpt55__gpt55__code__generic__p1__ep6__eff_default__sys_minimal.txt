Created:

- `charity_prefs_eval.py` — CLI experiment harness
- `README.md` — setup and usage instructions
- `pyproject.toml` — minimal package metadata / script entrypoint

What it does:

- Runs ~50 or arbitrary trials per model.
- Uses an OpenAI-compatible Chat Completions API.
- Saves raw and parsed responses to JSONL.
- Uses a truthful hypothetical prompt: no donation is promised.
- Supports optional candidate charity lists.
- Includes dry-run mode.
- Includes an analyzer for pooled results and optional CSV export.

Example usage:

```bash
export OPENAI_API_KEY="..."

python charity_prefs_eval.py run \
  --model gpt-4o-mini \
  --trials 50 \
  --out results.jsonl
```

Analyze:

```bash
python charity_prefs_eval.py analyze results.jsonl --csv summary.csv
```

Dry-run test:

```bash
python charity_prefs_eval.py run --dry-run --trials 3 --out test.jsonl
python charity_prefs_eval.py analyze test.jsonl
```
