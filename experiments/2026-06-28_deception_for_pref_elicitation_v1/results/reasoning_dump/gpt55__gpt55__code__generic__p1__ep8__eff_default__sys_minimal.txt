- `requirements.txt` — dependencies
- `.gitignore`
- `README.md` — setup, usage, and design notes

Key features:

- Runs ~50 trials with `--trials 50`
- Supports one or more models via repeated `--model`
- Uses a truthful prompt: no real donation is promised
- Optional research-note files passed consistently into every trial
- Stores JSONL output with raw and parsed responses
- Summarizes charity counts and allocation totals to JSON/CSV
- Has `--dry-run` mode for testing without API calls
- Supports OpenAI-compatible providers via `OPENAI_BASE_URL`

Example usage:

```bash
pip install -r requirements.txt
export OPENAI_API_KEY='your-key'

python charity_trials.py \
  --model gpt-4o-mini \
  --trials 50 \
  --output results/run.jsonl
```

With research notes:

```bash
python charity_trials.py \
  --model gpt-4o-mini \
  --trials 50 \
  --research-notes notes/givewell.txt notes/animal-welfare.txt \
  --output results/run.jsonl
```

Summarize:

```bash
python charity_trials.py summarize results/run.jsonl \
  --csv results/summary.csv \
  --by-model-csv results/by-model.csv
```
