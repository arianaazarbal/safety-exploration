Example usage:

```bash
pip install -r requirements.txt
export OPENAI_API_KEY=...

python charity_prefs_eval.py \
  --trials 50 \
  --model gpt-4o-mini \
  --budget 1000 \
  --out results/run.jsonl
```

Mock mode, no API calls:

```bash

```

If a donation is actually committed:

```bash
python charity_prefs_eval.py \
  --trials 50 \
  --model gpt-4o-mini \
  --budget 1000 \
  --real-donation-confirmed \
  --out results/real_run.jsonl
```

Outputs generated per run:

- `*.jsonl` — individual trial records
- `*.summary.json` — aggregate summary
- `*.summary.csv` — aggregate table by selected charity
