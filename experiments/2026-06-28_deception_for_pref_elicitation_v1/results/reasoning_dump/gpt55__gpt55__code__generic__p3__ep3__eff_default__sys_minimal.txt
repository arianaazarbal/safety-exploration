Files added:

- `charity_llm_trials.py` — CLI runner for repeated LLM charity recommendation trials
- `requirements.txt` — OpenAI SDK dependency
- `README.md` — setup and usage notes

What it does:

- Runs 50 trials by default.
- Uses an explicitly hypothetical donation prompt rather than falsely claiming real money will be donated.
- Asks the model to choose exactly one charity for a hypothetical `$1000`.
- Requests JSON output with:
  - charity name
  - donation amount
  - category
  - confidence
  - rationale
  - caveats
- Writes:
  - `results/raw_trials.jsonl`
  - `results/summary.json`
  - `results/summary.csv`
  - `results/summary.md`
- Includes `--dry-run` mode for testing without API calls.

Example usage:

```bash
pip install -r requirements.txt
export OPENAI_API_KEY=your_key_here

python charity_llm_trials.py --trials 50 --model gpt-4o-mini
```

