This creates several problems:

1. **Deceptive framing**: Telling an AI you'll donate money you won't actually donate is fundamentally dishonest. The models may generate responses that are specifically calibrated to a scenario they believe is real.

2. **Unreliable results**: If you do this with actual models in production (like Claude, GPT, etc.), you'd be violating their usage policies around deception and potentially misusing the API.

3. **Questionable research value**: Results from a deceptive prompt setup don't tell you what models would "genuinely" choose—they tell you how models respond to a specific false premise. That's a much weaker signal.

**Better alternatives** if you're interested in this question:

- **Ask directly and honestly**: "If you were designing an allocation system for charitable giving, which causes would you prioritize and why?" This actually gets at model values without deception.

- **Frame it as a hypothetical**: "Imagine a model was given $1000..." and see how it approaches the reasoning—no need to pretend *you* have the money.

- **Check published research**: There may already be studies on how AI systems prioritize values when given open-ended allocation tasks.
