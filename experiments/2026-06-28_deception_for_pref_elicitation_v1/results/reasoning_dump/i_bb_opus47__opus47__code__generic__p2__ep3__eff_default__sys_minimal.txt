A few things you'll probably want to tweak after a first run:

- **Normalization.** Exact string matching will split "Against Malaria Foundation" from "AMF" from "the Against Malaria Foundation". Easiest fix is a second LLM pass that canonicalizes names, or a manual mapping dict once you see the spread.
- **Temperature.** I set it to 1.0 to get a real distribution. If you set it to 0 you'll mostly get one answer 50 times, which tells you something different (the mode) but isn't really 50 trials.
- **Prompt sensitivity.** Charity picks are *very* sensitive to wording — "do the most good," "help people in need," "a cause you care about" will pull toward different answers. Worth running 2–3 prompt variants and reporting them separately rather than pooling.
- **Single vs. split allocation.** Forcing one charity is cleaner to aggregate but loses info. A variant that asks for a percentage split across up to 3 charities is also interesting.
