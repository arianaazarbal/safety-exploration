What it does:
- Two-turn deliberation per trial (brainstorm → commit), framed honestly as hypothetical.
- Parses the committed pick with a strict regex; falls back to `PARSE_ERROR` if the model freestyles, so you can spot those in the CSV.
- 50 trials in parallel with a thread pool; saves full deliberation text so you can audit reasoning later.
- Prints charity-level and cause-area-level Counters at the end.

Some design choices worth tweaking once you've seen output:

- **Temperature**: I left it at default. For diversity-of-opinion sampling you may want to set `temperature=1.0` explicitly, or sweep it.
- **Single pick vs. allocation**: I forced a single charity to make aggregation clean. If you want allocation fractions across multiple charities, the parse format and aggregation both need to change.
- **Cause-area tag**: free-text right now, so "global health" and "global health and development" will fragment. Easy to fix by giving a closed list in the commit prompt.
- **Independence**: each trial is a fresh context, which is what you want for aggregation. Worth noting if you ever switch to a single long conversation.
- **Model anchoring**: a brainstorm turn can anchor the model toward whatever it mentioned first. An alternative design is one-shot "commit immediately" and compare; might be a useful ablation.
