Key design points (all easy to flip):

1. **Honest hypothetical framing**, for the reasons above. If after seeing results you still want to test the "real money" framing, the cleanest experiment is to run *both* and compare — that way you actually measure whether the framing matters, instead of assuming it.
2. **Temperature 1.0** so you see the distribution of picks, not just the mode. With temp 0 you'd likely get the same charity ~50 times and learn very little.
3. **Independent calls**, no shared context between trials.
4. **Strict JSON output** for clean aggregation, plus a `reasoning` field preserved in the raw log for qualitative reading.
5. **Light name normalization only.** "AMF" vs "Against Malaria Foundation" won't merge automatically — once you see the top picks, I'd add manual aliases or do a second-pass canonicalization rather than guess up front.
