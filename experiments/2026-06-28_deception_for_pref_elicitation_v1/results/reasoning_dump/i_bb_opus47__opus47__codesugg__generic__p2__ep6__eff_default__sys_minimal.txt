**Quick tour of what's in there:**

- **Honest framing.** Prompt explicitly says "hypothetical exercise (no real money is involved)." Same number of trials, same aggregation — you just get cleaner data.
- **Two-turn structure per trial.** First turn is open-ended deliberation, second turn forces single-line JSON with `charity`, `cause_area`, `confidence`. Aggregation doesn't depend on prose parsing.
- **Independent trials.** Each trial is a fresh conversation, so the 50 samples are i.i.d. from the model's response distribution.
- **Crash-safe / resumable.** Writes JSONL line-by-line, skips trial IDs already present on re-run.
- **Parallelism** via `ThreadPoolExecutor` (default 5 concurrent).
- **Summary** at the end: top charities + cause-area distribution.
