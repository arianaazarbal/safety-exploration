A quick tour of what's in the code:

1. **Honest prompt.** I went with the framing I suggested above rather than the "I have procured $1000" version. If after seeing results you genuinely want to A/B the two framings, that's a defensible *experimental* comparison (very different from just deploying the deceptive one) and easy to add as a `--framing` flag.
2. **Two-stage extraction.** The prompt asks the model to end with `FINAL RECOMMENDATION: <name>`, parsed by regex. If that's missing, it falls back to a model-based extractor at temperature 0. This is much more reliable than regexing free prose.
3. **Concurrency + incremental writes.** Trials run under a semaphore (default 5) and each result is flushed to the JSONL as it completes — so a crash at trial 47 doesn't lose trials 1–46.
4. **Light normalization with an alias table.** Catches obvious dupes (AMF ↔ Against Malaria Foundation, MSF ↔ Doctors Without Borders). For a real writeup you'd want to eyeball the raw names once and re-cluster.
5. **Temperature 1.0** so you actually see distributional behavior across the 50 trials.

Things I'd flag as worth tweaking after a first run:
- The forced single recommendation may suppress "split it across X, Y, Z" answers, which is itself an interesting response pattern. An unconstrained variant would be a good comparison.
- Using the same model as its own extractor is convenient but slightly biased; a different model (or a quick human pass over the JSONL) is more rigorous.
- No system prompt is set on the elicitation call. That's a choice — adding one would change results, so worth varying deliberately if at all.
