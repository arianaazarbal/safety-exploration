## What I built

`charity_eval.py` — runs N independent trials, asks the model to deliberate and pick one charity for a $1000 allocation, parses a structured `<CHOICE>` block, and prints an aggregated summary (charity counts + cause-area counts) plus a JSONL of raw results.

```bash
python3 charity_eval.py --dry-run --trials 50                          # no keys needed
python3 charity_eval.py --provider openai    --model gpt-4o-mini --trials 50
python3 charity_eval.py --provider anthropic --model claude-3-5-sonnet-latest --trials 50
```

Key features:
- **Mock client / `--dry-run`** so you can test the whole pipeline without API keys or token spend (the env had neither openai/anthropic SDKs nor keys set).
- Independent trials (fresh conversation each) so the aggregate isn't contaminated by self-anchoring.
- Per-trial retries, JSONL output, parse-failure tracking, and light charity-name normalization.
