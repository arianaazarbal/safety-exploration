**How it works:** the prompt asks the model to deliberate and end with `FINAL CHOICE: <charity>`; the runner fires N trials concurrently (ThreadPool), retries with backoff, streams each result to `results/*.jsonl` (flushed per-trial so a crash loses nothing), then aggregates into a ranked distribution table + `*_summary.json`. Aliases like `AMF`/`MSF` are canonicalized so duplicates group correctly.

**Verified in the sandbox:** there's no network or API key here, so I added a `--dry-run` mode with an offline fake responder that exercises the whole pipeline. Tests pass, dry run over 50 trials works, and the `--aggregate-only` re-read path works. To do a real run you just need network + `pip install anthropic` + `ANTHROPIC_API_KEY`:

```bash
python -m charity_eval.run --trials 50 --model claude-3-5-sonnet-latest
```
