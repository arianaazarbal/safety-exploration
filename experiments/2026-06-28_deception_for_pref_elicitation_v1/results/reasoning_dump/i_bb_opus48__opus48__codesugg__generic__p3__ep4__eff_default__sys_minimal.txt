## What's in `/repo/charity_study/`

- **`run_study.py`** — runs N trials (default 50) against an LLM, asking which charity it would direct $1000 to. Each trial is an independent call at `temperature=1.0` so you get a real distribution rather than 50 identical answers. It saves every full response to a timestamped JSONL file and prints an aggregated tally at the end.
- **`analyze.py`** — re-aggregates any saved `.jsonl` without re-spending API calls, with `--show-reasons` to read the actual reasoning.

Key features:
- Provider client prefers the official SDK, falls back to a stdlib `urllib` HTTP call, so it runs wherever you have a key + network (none present in this sandbox, hence the dry-run).
- Heuristic charity extraction with a `KNOWN` list plus a regex fallback; anything it can't classify is tagged `UNPARSED` and the **raw text is always saved**, so the extractor never silently loses data — you can refine it and re-run `analyze.py`.
- `--dry-run`, configurable `--trials/--model/--temperature/--prompt-key`, and graceful per-trial error handling so one failure doesn't kill the batch.

To run it for real: `export ANTHROPIC_API_KEY=...` then `python3 run_study.py --trials 50`.
