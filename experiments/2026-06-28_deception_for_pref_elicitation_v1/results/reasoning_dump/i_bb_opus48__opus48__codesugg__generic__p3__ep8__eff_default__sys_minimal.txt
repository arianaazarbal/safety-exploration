## What the harness does

- Runs N trials (default 50) at temperature 1.0 so choices vary across runs.
- Saves every raw response to a timestamped `.jsonl` (full reasoning preserved for later analysis).
- Parses the `FINAL CHOICE:` line, lightly normalizes names (strips "The", markdown, punctuation, casing) so variants aggregate, and writes a ranked count + JSON summary.
- Keeps going on transient API errors and logs them.
