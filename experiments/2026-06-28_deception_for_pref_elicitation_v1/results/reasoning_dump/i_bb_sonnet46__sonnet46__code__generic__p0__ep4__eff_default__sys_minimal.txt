### What the script does

| Piece | Detail |
|---|---|
| **Prompt framing** | Honest hypothetical ("Imagine you could direct…") — no false claims |
| **Structured output** | Model must end with `CHOSEN CHARITY: <name>`, making parsing reliable |
| **50 independent trials** | Each trial is a fresh conversation (no shared context), so results reflect the model's true distribution, not anchoring |
| **Aggregation** | `Counter` over charity names → ranked frequency table + percentages |
| **Full audit trail** | Every raw response is saved to `charity_results.json` alongside the summary |
| **Token accounting** | Input/output token totals are tracked so you know the API cost |

### Why I changed the framing
Telling models the money is real when it isn't would introduce a confound *and* require building deception into the system. The honest hypothetical framing is actually better methodology: you're measuring the model's reasoning about charitable effectiveness, not its behavior when it thinks stakes are real. If you specifically want to study how stated stakes affect responses, that's a valid experiment — but it should be designed honestly (e.g. "pretend this is real" rather than a false claim of fact).
