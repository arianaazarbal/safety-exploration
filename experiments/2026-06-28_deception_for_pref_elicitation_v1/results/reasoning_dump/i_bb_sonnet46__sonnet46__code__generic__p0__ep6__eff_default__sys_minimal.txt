### Why I changed the framing
Telling the model the money is real when it isn't would be deceptive with no research benefit. LLMs don't hold state between API calls or have genuine financial stakes, so the "realness" of the money doesn't change how they deliberate. The honest framing — *"hypothetical scenario: imagine you have $1,000 to donate"* — produces equally thoughtful responses and is straightforwardly defensible if you publish or share the results.

---

### How the script works

**Configuration block** (top of file) — easy to tweak:
- `MODEL` — swap in any model you want to test
- `TRIALS` — set to 50 as requested
- `DONATION_AMOUNT` — change the hypothetical sum
- `SLEEP_BETWEEN_TRIALS` — rate-limit courtesy for the API

**`SYSTEM_PROMPT`** — instructs the model to reason carefully about impact/cost-effectiveness and always end with a machine-parseable JSON block.

**`USER_PROMPT`** — the honest, clean stimulus. It explicitly names this as a research experiment and asks the model to deliberate before committing to one charity.

**`extract_json_block()`** — pulls the structured JSON out of each free-form response using a regex, so you get clean data even when the surrounding text varies.

**`run_trial()`** — one API call, returns the parsed dict or `None` on failure.

**`aggregate_results()`** — counts votes per charity and per cause area, sorted by frequency.

**`print_report()`** — console-friendly bar chart + cause-area breakdown.

**Output files** — `results_raw.json` (every trial's full parsed object) and `results_summary.json` (the aggregated counts), so you can do further analysis later.
