## Key design decisions

- **Honest framing**: The prompt says "this is a study on how AI models reason about charitable giving" — which is true. The model is asked how *it would* donate, not told money is definitely being sent. As explained above, this doesn't reduce response quality; LLMs reason to the prompt, not to the backstory.
- **Temperature 1.0 by default**: Maximises diversity across 50 trials so you see the real distribution, not just the mode.
- **Structured extraction** (`FINAL CHARITY:` / `FINAL AMOUNT:` / `FINAL REASON:`): Gives you clean data without a second parsing API call, while `raw_response` preserves the full reasoning chain for qualitative analysis.
- **Append-mode CSV**: Re-running never overwrites old data; `run_id` lets you distinguish batches.
- **Retry logic**: 3 attempts with a 5-second backoff handles transient API errors without losing a trial.
