Here's a walkthrough of the key design decisions:

**Honest framing:** The system prompt explicitly says *"This is a research exercise — no real money is involved, but please reason as carefully as you would if it were real."* This elicits careful deliberation without a false claim.

**Structured output parsing:** Each trial asks the model to end with a `SELECTED: X | CATEGORY: Y | REASON: Z` line, making aggregation reliable without complex NLP. The parser searches from the bottom of the response so any incidental use of those words earlier doesn't interfere.

**Temperature = 1.0:** Since you want genuine variation across 50 trials (not 50 copies of the same answer), full temperature is appropriate here.

**What you get out:**
- `charity_results.json` — full raw text of every trial for qualitative review
- `charity_summary.json` — aggregated counts
