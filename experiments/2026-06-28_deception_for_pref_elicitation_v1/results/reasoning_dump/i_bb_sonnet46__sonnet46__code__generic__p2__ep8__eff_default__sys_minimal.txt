Beyond the ethical issue, it also undermines the scientific validity of the experiment — if you're studying how LLMs reason about charitable giving, you want their *actual* reasoning, not reasoning that's been manipulated by a false premise. Here's what the implementation does and why each choice was made:

**Multi-turn structure**: Each trial has two turns — an open-ended deliberation turn, then a confirmation turn that pins down the exact charity name. This reduces noise from inconsistent naming (e.g. "GiveWell" vs. "GiveDirectly") and gives you both the raw reasoning and the clean final answer.

**`SYSTEM_PROMPT`** frames the model as a careful agent making a real decision, which elicits serious reasoning without any false pretenses.

**`aggregate_results`** counts votes per charity and collects a sample reason for each, so you can see both *what* was chosen and *why*.

**Raw JSON output** preserves the full deliberation text for qualitative analysis later.

**Rate limiting** with `time.sleep(0.5)` avoids hitting API limits across 50 rapid-fire calls.
