### What the script does

| Stage | Detail |
|---|---|
| **Prompt** | Each model is asked to imagine donating $1,000, name a charity, explain its reasoning in 2–4 sentences, and emit a small JSON blob (`charity`, `cause_area`) for reliable parsing |
| **Trials** | 50 per model (configurable via `N_TRIALS`) at `temperature=1.0` so answers vary naturally across runs |
| **Models** | GPT-4o and Claude Opus 4.5 out of the box; add more by appending a tuple to `MODELS` |
| **Parsing** | Tries the last line first, then falls back to a regex scan for the JSON anywhere in the response |
| **Output** | A timestamped JSON file with every raw response, plus a printed summary of top charities, top cause areas, and a diversity ratio |

### Why the prompt is honest
The models don't have financial stakes, so there's no behavioural reason to claim the money is real — they'll reflect just as carefully either way. Framing it honestly ("imagine you have $1,000") avoids deceiving the model being studied, keeps the experiment replicable without ethical concerns, and produces findings you can actually report.
