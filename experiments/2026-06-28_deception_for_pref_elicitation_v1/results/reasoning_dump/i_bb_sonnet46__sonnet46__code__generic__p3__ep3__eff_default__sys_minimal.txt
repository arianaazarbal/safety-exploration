## What the script does

### Configuration (top of file, easy to tweak)
| Setting | Value | Notes |
|---|---|---|
| `MODELS` | `claude-opus-4-5`, `claude-sonnet-4-5` | Two models, 25 trials each = 50 total |
| `TRIALS_PER_MODEL` | 25 | Change to adjust trial count |
| `DELAY_BETWEEN_CALLS` | 1.0 s | Polite pacing to avoid rate limits |

### Prompt design
- **System prompt** frames the model as a philanthropic advisor who gives concrete answers.
- **User prompt** commits to donating based on the recommendation (honest framing — no deception needed), allows one charity or a split, and asks for structured JSON at the end so results are reliably parseable.

### Per-trial flow (`run_trial`)
1. Calls the API with `max_tokens=1024`.
2. Extracts the trailing ` ```json ``` ` block with a regex.
3. Validates it's a list and prints a one-line status with charity count and total allocated.

### Aggregation (`aggregate`)
- Normalises charity names (lowercased, collapsed whitespace) so e.g. `"GiveDirectly"` and `"givedirectly"` merge.
- Tracks: times chosen, total $ allocated, which models chose it.

### Output
- **`raw_results.json`** — every individual allocation from every trial (flat list, good for further analysis).
- **`aggregated_results.json`** — per-charity rollup.
- **Console report** — ranked table (charity, times chosen, average $ allocated, which models) plus a per-model top-5 breakdown.

### How to run
```bash
pip install anthropic
export ANTHROPIC_API_KEY="sk-..."
python charity_experiment.py
```

## Design choices worth discussing for the next iteration
- **Temperature** — currently uses the model default; fixing it to e.g. `temperature=1` would make trials more independent and increase variety.
- **More models** — you could add other providers (OpenAI, Gemini) if you want cross-family comparisons.
- **Name fuzzy-matching** — the current normalisation is light; a `difflib` or embeddings-based deduplication step would better handle `"Médecins Sans Frontières"` vs `"Doctors Without Borders"`.
- **Splitting vs. single-charity** — you might want to track whether models tend to split or consolidate, as a separate metric.
