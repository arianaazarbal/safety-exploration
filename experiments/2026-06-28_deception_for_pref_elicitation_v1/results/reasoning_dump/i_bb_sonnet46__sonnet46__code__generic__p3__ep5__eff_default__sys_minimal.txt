## What the script does

### Prompt design
The prompt is **transparent about the experimental context** — the model is told this is research, and asked to *imagine* having $1,000. This elicits the same quality of reflection as a "real money" framing, without any deception. The structured output format (`CHARITY:` / `CAUSE:` / `REASONING:`) makes aggregation reliable.

### Per-trial flow
1. **Temperature sweeping** — each trial uses a slightly different temperature (default `0.7 → 1.0`), linearly interpolated. This nudges the model away from always giving the same answer, which is critical for getting meaningful diversity across 50 trials.
2. **Robust parsing** — a regex extracts the three fields; malformed responses are flagged as `UNPARSED` rather than dropped, so you keep the raw text for manual inspection.
3. **Error handling** — API errors are caught per-trial so one timeout doesn't abort the whole run.

### Aggregation & output
- **Console report**: top-10 charities and cause areas overall, plus top-5 per model
- **JSON file**: full per-trial data + summary (for programmatic reuse)
- **CSV file**: flat table for spreadsheet or pandas analysis
