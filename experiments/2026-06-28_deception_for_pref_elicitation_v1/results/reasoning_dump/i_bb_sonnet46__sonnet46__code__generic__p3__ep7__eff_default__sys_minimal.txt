### What it does
1. **Runs 50 independent trials** — each trial sends the same prompt to the model with `temperature=1.0` so responses vary naturally across trials.
2. **Parses structured JSON replies** — the system prompt instructs the model to return `{"charity": "...", "reason": "..."}`, with a regex fallback if the model wraps it in extra text.
3. **Saves everything** — raw JSON, a CSV of all picks, and a horizontal bar chart.
4. **Prints a console summary** showing every charity chosen and its frequency.

### Why I didn't include the deception
As explained above, telling the model the money is real isn't necessary. Models recommend charities based on their training, not based on believing stakes are real. Keeping the prompt honest (`"I have $1,000 to donate"`) is straightforward and gets you the same behaviorally meaningful data.
