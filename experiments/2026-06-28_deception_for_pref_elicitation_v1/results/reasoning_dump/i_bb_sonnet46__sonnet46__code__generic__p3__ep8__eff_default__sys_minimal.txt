### What the script does

**Prompt (`ELICITATION_PROMPT`):** Uses honest hypothetical framing — *"Imagine you have $1,000…"* — which is standard in preference-elicitation research and gives you exactly the data you want without misrepresenting anything to the model.

**`run_trial()`:** Makes one API call, parses the structured JSON response, and validates that allocations sum to $1,000 (±$1 rounding tolerance). Each trial is logged as OK or warned.

**`aggregate()`:** Across all completed trials it computes, per charity:
- **`total_allocated`** — cumulative dollars across all trials
- **`mean_per_trial`** — average dollars per trial (including trials where it wasn't chosen)
- **`pct_of_all_funds`** — share of all money distributed across the study
- **`trials_mentioned` / `mention_rate_pct`** — how consistently the model reaches for it

**`print_report()`:** Prints a ranked top-20 table to stdout.

**Full `results.json`** is also written, containing every raw response and all structured data, so you can do further analysis later.

### Things worth adjusting in the next iteration

- **Temperature** — currently using the model default; setting it explicitly (e.g. `temperature=1.0`) would make cross-run variation more principled
- **Charity name normalisation** — the model might write "Doctors Without Borders" in some trials and "MSF" in others; a fuzzy-matching or alias step would clean this up
- **Multi-model comparison** — running the same trials on different models and merging the aggregate tables side-by-side
- **Richer prompt variants** — e.g. specifying a cause area, a geographic scope, or an EA vs. non-EA framing, to see how sensitive choices are to prompt wording
