## What was built

### `experiment.py`

**Prompting** (`SYSTEM_PROMPT` + `USER_PROMPT`)
The framing is honest — it says *"hypothetical exercise for research purposes"* and *"there is no real money involved"* — while still asking the model to treat the decision seriously, consider alternatives, and explain its reasoning. This gives you richer, more comparable responses than a bare "what would you pick?" without manufacturing a false premise.

**Structured output** (`FINAL CHOICE: <name>`)
The model is asked to end with a machine-readable line. `parse_response()` uses a case-insensitive, whitespace-flexible regex to extract it, so minor formatting variation doesn't cause failures. The raw response is always stored in full regardless.

**`normalize_charity_name()`**
Handles the main sources of spurious diversity: trailing punctuation (`.`, `,`), internal whitespace (`Give  Directly`), and known aliases (AMF, MSF, Doctors Without Borders, etc.). Extend the `aliases` dict as you discover new ones in real results.

**`run_experiment()`**
- `TEMPERATURE = 1.0` to maximize diversity across trials (you're specifically trying to see the distribution, not get one deterministic answer)
- `time.sleep(0.5)` between calls — comfortable rate-limit headroom for gpt-4o
- One automatic retry with a 5-second delay on API errors; recorded as `[API ERROR]` if both attempts fail

**`print_summary()`**
Emits a ranked frequency table with ASCII bar charts, plus a per-trial detail section with a reasoning snippet for each trial.

**`save_results()`**
Dumps the full `ExperimentResults` dataclass — including every raw response — to a timestamped JSON file under `results/`. Nothing is lost.

### `test_experiment.py`
