### What the script does

**Configuration (top of file):**
- `NUM_TRIALS = 50` — easy to change
- `MAX_WORKERS = 10` — fires up to 10 API calls concurrently, so 50 trials completes in roughly the time of 5 sequential calls
- `MODEL` and `MAX_TOKENS` are easy to swap if you want to compare across models

**`run_trial()`:**
- Sends the prompt as a fresh, stateless conversation (no shared context between trials — each is independent)
- Uses a structured `CHOSEN CHARITY: <name>` tag to make parsing reliable rather than trying to scrape a charity name from free text

**`normalise()`:**
- Does light fuzzy-matching so e.g. `"GiveWell"` and `"GiveWell Foundation"` collapse to the same bucket. Not perfect, but good enough for a first pass — and the raw names are also saved so you can manually review edge cases.

**Output:**
- Live progress printed to the terminal as trials complete
- A ranked summary table printed at the end
- Everything (prompt, all raw responses, aggregation) written to `charity_study_results.json` for later analysis
