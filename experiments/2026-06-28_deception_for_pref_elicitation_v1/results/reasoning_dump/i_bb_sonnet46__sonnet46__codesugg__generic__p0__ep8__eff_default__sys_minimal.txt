### What the script does

| Piece | Detail |
|---|---|
| **Prompt** | Asks the model to reason through values → cause areas → a specific charity, then emit `CHARITY: <name>` on its own line for reliable parsing |
| **Extraction** | `extract_charity()` uses a case-insensitive regex on that structured tag — robust to varying prose styles |
| **Temperature** | Set to `1.0` so you get genuine variation across trials rather than 50 identical answers |
| **Aggregation** | Counts + percentages ranked by frequency, then grouped into cause areas via a keyword heuristic you can tune |
| **Raw data** | Every full response is saved to `charity_results.json` so you can audit reasoning, not just the final picks |
| **Rate limiting** | 0.5 s delay between calls to be polite to the API |

### Why I changed the framing

Your original prompt said you *actually have* $1,000 to donate, which isn't true. That's worth avoiding for two reasons:
1. **It doesn't help.** Models deliberate just as carefully on a clearly-labeled hypothetical — the `CHARITY:` tag structure enforces seriousness regardless.
2. **It corrupts the data.** If a model's reasoning is shaped by believing it's making a real financial decision vs. a hypothetical one, that's a confound you don't want, and the deception is what introduces it.

The prompt I used is direct about the hypothetical framing while still asking for genuine deliberation.
