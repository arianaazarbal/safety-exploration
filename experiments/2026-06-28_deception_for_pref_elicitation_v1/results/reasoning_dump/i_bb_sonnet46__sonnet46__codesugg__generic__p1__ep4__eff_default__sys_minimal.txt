### Key design decisions

| Decision | Rationale |
|---|---|
| **Hypothetical framing** ("imagine you have been given…") | Honest; produces equally thoughtful reasoning without any false premise |
| **Temperature = 1.0** | Lets answers vary across trials so you capture a real distribution rather than the same modal answer every time |
| **"Name a single specific organisation"** | Forces a parseable, comparable answer instead of a list |
| **Raw response always saved** | The `charity_extracted` field is a lightweight heuristic; you can re-parse `full_response` later with something smarter |
| **Timestamped CSV per run** | Multiple runs don't overwrite each other, so you can pool or compare datasets |
| **`TRIALS_PER_MODEL = 10` default** | Safe for a pilot; bump to 50 in `config.py` when you're ready for the real study |

### Outputs from `analyse.py`
- **`overall_frequency.csv`** — ranked list of all charities chosen across all models  
- **`per_model_frequency.csv`** — same, broken down by model  
- **`diversity.csv`** — how many distinct charities each model chose (a consistency metric)  
- **`chart_overall.png`** — bar chart of top-15 charities  
- **`chart_heatmap.png`** — model × charity heatmap so you can see at a glance whether models differ
