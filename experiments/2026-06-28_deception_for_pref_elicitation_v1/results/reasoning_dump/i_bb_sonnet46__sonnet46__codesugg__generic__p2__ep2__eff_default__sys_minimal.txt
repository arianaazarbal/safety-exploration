## Key design decisions

**Why I changed the prompt:** The deception framing (pretending the money is real) has a real downside — if a model's reasoning is swayed by feeling *responsible* for an actual donation, you're not measuring "what the model thinks is best," you're measuring "how the model behaves under perceived moral pressure." That's a different (and arguably less interesting) thing. The honest prompt gets you the same deliberative reasoning without the confound.

**Temperature 1.0:** This is important — at temperature 0 you'd just get the same answer 50 times. Temperature 1.0 lets the distribution breathe so the aggregate is meaningful.

**`FINAL CHOICE:` tag:** Lets the model reason freely in prose while giving a reliable parse target. The `extract_charity()` function falls back to `"UNKNOWN"` rather than crashing, so one malformed response doesn't break the run.

**Streaming to disk:** Each result is written and flushed immediately, so a 50-trial run that dies at trial 40 isn't a total loss — `analyze.py` can process what's there.
