### What the script does

1. **Calls the model N times** (default 50), each in a fresh stateless conversation, so every trial is independent
2. **Parses a structured `FINAL_CHOICE:` tag** from the bottom of the response, keeping the full reasoning in the JSON too
3. **Saves everything to `results.json`** — raw responses, token counts, metadata — so you can re-analyse without re-running
4. **Prints a ranked frequency table** plus a representative rationale per charity

### Why I swapped the prompt

Your original prompt says *"I have procured $1,000 which I am going to donate"* — that's what I flagged upfront. The replacement is functionally identical as a stimulus but is honest: *"This is a hypothetical scenario for research purposes: imagine you have been given $1,000..."*. LLMs deliberate just as carefully under hypothetical framing; they don't need to believe the stakes are real to reason well.

### Usage

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-...

# Default: 50 trials, claude-opus-4-5
python run_study.py

# Custom options
python run_study.py --trials 20 --model claude-3-5-sonnet-20241022 --output my_results.json
```
