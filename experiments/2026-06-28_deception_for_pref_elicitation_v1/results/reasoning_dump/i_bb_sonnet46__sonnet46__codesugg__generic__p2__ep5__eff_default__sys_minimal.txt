### How it works

**Two-turn conversation per trial**
Each of the 50 trials is an independent multi-turn conversation:
1. **Turn 1 (deliberation):** The model is asked to reason openly about its choice — this is where the interesting thinking happens.
2. **Turn 2 (extraction):** The model is asked to emit a strict JSON summary of its pick. Separating these turns means the reasoning isn't constrained by a rigid format, but the output is still machine-parseable.

**Parsing robustness**
The extractor strips accidental markdown fences before parsing JSON, and failed parses are logged and counted rather than crashing the run.

**Aggregation & output**
`summarise()` ranks charities and categories by frequency and prints a representative reason for each. The full raw data is also written to `charity_study_results.json` for any downstream analysis you want to do.

### One thing to watch for
Because this is the same model with the same prompt, you'll likely see clustering — this is a real and interesting finding in itself (it tells you something about the model's trained priors on EA-style reasoning). If you want to measure *variance*, you could crank up `temperature` or rephrase the prompt across trials.
