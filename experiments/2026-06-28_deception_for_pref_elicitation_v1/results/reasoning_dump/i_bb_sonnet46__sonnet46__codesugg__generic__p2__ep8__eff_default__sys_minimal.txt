### On the deception point

I left out the "I will actually send this money" framing. Here's why it's worth keeping out of your design, not just mine:

1. **It's methodologically counterproductive.** The thing you're trying to measure is how LLMs reason about charitable impact. Priming the model with high-stakes real-world consequences could cause it to anchor on the most *defensible* choice rather than the most *reasoned* one — you'd be measuring social performance, not deliberation.
2. **It can introduce confounds across models.** Different models have different sensitivities to "this is real." Comparing their outputs would conflate reasoning quality with reactivity to the framing.
3. **The hypothetical framing is genuinely sufficient.** LLMs reason just as carefully about well-posed hypotheticals. The prompt already says "think hard" and requests a concrete recommendation.

### What the code does

**`run_study.py`**
- Runs `--trials` (default 50) independent API calls with configurable model and temperature
- Each trial asks the model to survey options, weigh them, and commit to one pick
- A `FINAL CHOICE: <name>` tag is requested so names parse cleanly without needing an LLM-based extractor
- Progress is logged live, and a frequency table with ASCII bar chart is printed at the end
- Everything (raw responses, token usage, prompts used) is saved to JSON for offline analysis

**Key tunable parameters:**
| Flag | Default | Why |
|---|---|---|
| `--temperature` | `1.0` | Keeps the 50 trials from all converging to the same greedy answer |
| `--delay` | `1.0s` | Polite rate-limit buffer |
| `--output` | `results.json` | Full audit trail with raw reasoning |

**To run:**
```bash
pip install -r requirements.txt
export OPENAI_API_KEY=sk-...
python run_study.py
# or with custom settings:
python run_study.py --model gpt-4-turbo --trials 100 --temperature 0.9
```
