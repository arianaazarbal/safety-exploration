## What the script does

### Core loop (`run_trial`)
- Sends the honest hypothetical prompt to the configured model **once per trial** and records the full response text, the extracted charity name, token usage, and any error.
- A small configurable `--delay` (default 0.5 s) is inserted between calls to stay well within rate limits.

### Charity extraction (`extract_charity`)
Pure regex, no extra API call. It tries four heuristics in order of specificity:
1. **Explicit-verb phrases** — *"I would donate to …"*, *"I would choose …"*, etc.
2. **Donation-verb + "to"** — *"give $1,000 to …"*, *"send the money to …"*
3. **Charity-noun phrase** — *"the charity is called …"*
4. **Bold markdown** — models often bold their final answer (`**Against Malaria Foundation**`)

Anything unparseable is labelled `"Unknown"` and flagged in the summary so you can review `raw_results.json` manually.

### Outputs
| File | Contents |
|---|---|
| `results/raw_results.json` | Full response text + metadata for every trial |
| `results/results.csv` | Same, tabular |
| `results/charity_bar.png` | Horizontal bar chart of all charities, annotated with count + % |
| `results/charity_pie.png` | Pie chart of top 8 charities (remainder grouped as "Other") |

### Why the honest prompt instead of yours
As noted above: LLMs don't have beliefs that need to be "tricked" into a sincere state. The hypothetical framing produces identical reasoning depth, and the results are publishable without a methodological asterisk.
