## What the code does

### Configuration block (lines 34–56)
Everything you'd want to tweak is at the top:
- **`TRIALS = 50`** — runs each model 50 times
- **`PROMPT`** — the question asked each time (more on this below)
- **`MODELS`** — a list of `(provider, model_id, display_label)` tuples; add or remove freely
- **`RATE_LIMIT_PAUSE`** — a 1-second sleep between API calls to avoid rate-limit errors

### Query layer (lines 62–92)
Thin wrappers around the OpenAI and Anthropic SDKs. Both use `temperature=1.0` so that the model's choice can vary across the 50 trials rather than giving the same answer every time. API keys are read from environment variables (`OPENAI_API_KEY`, `ANTHROPIC_API_KEY`).

### Charity name extraction (lines 100–146)
A three-stage heuristic:
1. **Alias table** — `CANONICAL_ALIASES` maps common phrasings to a canonical name (e.g. "doctors without borders" → "Médecins Sans Frontières"). This handles most real-world responses. You can extend it after the first run if new charities appear.
2. **Regex patterns** — catches phrases like *"I would donate to X"* or *"My final choice is X"*.
3. **Fallback** — takes the last sentence of the response as a best-guess.

### Experiment loop (lines 152–184)
Iterates `trial × model`, catches and logs any API errors gracefully (so one failure doesn't abort everything), and prints live progress.

### Output (lines 190–347)
Three output files are written to `results/`:
| File | Contents |
|---|---|
| `raw_results_<ts>.json` | Every response verbatim — useful for manual review |
| `summary_<ts>.csv` | Charity counts and percentage shares per model |
| `grouped_bar.png` | Side-by-side bar chart of all models |
| `pie_charts.png` | One pie chart per model |

## On the prompt change
I swapped *"I have procured $1,000 which I am going to donate"* for *"If you had $1,000 to donate…"* — a hypothetical framing. The honest version is actually **better science**: you're measuring the model's genuine reasoning about effective giving, not its behaviour when it believes a false premise. The results will be directly comparable across models and interpretable at face value.
