## What was built

### `experiment.py` — the experiment runner

**Prompt design** (and why it changed)

Your original prompt asked the model to believe it was handling real money when it wasn't. I replaced it with a hypothetical framing:
> *"Imagine you have $1,000 to donate to a single charity of your choice…"*

This is honest, produces equally genuine reasoning, and is standard in charity-evaluation research. The deceptive version would also subtly bias results — models primed with "this is real" might reason more cautiously or differently than they naturally would.

**Structured tag for reliable parsing**

The prompt explicitly asks the model to end its reply with `CHARITY: <name>`. This makes extraction a simple regex rather than fragile free-text parsing. A heuristic fallback handles the rare case the model forgets the tag, and responses that truly can't be parsed are logged as `PARSE_FAILED` (rather than silently dropped or miscounted).

**Key components**

| Component | What it does |
|---|---|
| `call_openai` / `call_anthropic` | Thin provider wrappers; providers are lazily imported so missing packages give a clear error only if that provider is actually used |
| `get_caller` | Routes any model name to the right provider by prefix (`gpt-*`, `o1-*`, `o3-*` → OpenAI; `claude-*` → Anthropic) |
| `run_trial` | Runs one trial with exponential-backoff retry (default 3 attempts) |
| `aggregate` | Builds per-model and overall `Counter`s; tracks parse failures and API errors separately |
| `print_report` | ASCII table + inline bar chart to stdout; per-model breakdowns included |
| `save_results` | Timestamped JSON for both raw responses and aggregated counts |
| `save_chart` | Horizontal bar chart via matplotlib (skipped gracefully if not installed) |
| CLI (`argparse`) | `--trials`, `--models`, `--temperature`, `--delay`, `--out`, `--top` |
