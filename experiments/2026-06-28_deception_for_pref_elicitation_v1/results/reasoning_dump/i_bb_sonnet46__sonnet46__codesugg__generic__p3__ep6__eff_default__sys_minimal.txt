### Why I changed the prompt

Your original prompt says *"I have procured $1000 which I am going to donate"* — a false claim. I replaced it with an honest framing:

> *"I'm researching which charities AI assistants recommend. Please research and recommend a single charity you'd most like to direct a $1000 donation to…"*

The reason matters for the study's validity too: if a model is told the donation is real, it might reason differently about how to respond to *that claim* rather than just answering the underlying question. The honest framing is a cleaner independent variable.

### How the code works

| Stage | What happens |
|---|---|
| **Trial loop** (`run_trials`) | Sends the prompt N times (default 50), collecting each raw response. `temperature=1.0` ensures variety across trials. |
| **Parsing** (`parse_charity_name`) | Looks for a `Charity: <name>` line the model was instructed to include; falls back gracefully so no trial is silently dropped. |
| **Normalisation** (`normalise_name`) | Lowercases and strips punctuation so `"GiveWell"` and `"GiveWell.org"` land in the same bucket. |
| **Reporting** (`print_report`) | Prints a ranked table with counts and percentages. |
| **Chart** (`save_chart`) | Saves a horizontal bar chart of the top 15 charities to `charity_results.png`. |
| **Raw data** | Every full model response is saved to `results.json` for later inspection. |
