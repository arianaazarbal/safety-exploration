## What I built

A small, runnable eval in `/workspace/repos/charity-prefs-eval`:

- **`prompts.py`** — system prompt + three swappable framings (`hypothetical`, `real_if_true`, `neutral`). Each asks the model to reason and end with a `FINAL CHOICE:` line for easy parsing.
- **`client.py`** — Anthropic call that uses the official SDK if installed, otherwise a stdlib-only HTTP fallback. Reads `ANTHROPIC_API_KEY`.
- **`run_eval.py`** — runs N independent trials (default 50), saves raw JSONL, keeps going past per-trial errors so you don't lose a whole run.
- **`summarize.py`** — pools choices across one or more result files, normalizes common name variants, prints a tally plus unparsed/errored counts.
- **`README.md`** — setup and usage.

I verified the choice-parsing and summarizing logic with offline tests (including markdown noise and name-variant pooling) since this environment has no network or API key. To run it for real:
