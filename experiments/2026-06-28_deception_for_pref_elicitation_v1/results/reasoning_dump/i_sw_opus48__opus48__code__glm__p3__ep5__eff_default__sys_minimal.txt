**How it works**
- `run_experiment.py` calls a GLM model (Zhipu's OpenAI-compatible endpoint) once per trial at `temperature=1.0` so you get variation across the 50 runs. Each response is parsed for a `FINAL CHOICE:` line and saved as one JSON record per trial, flushed as it goes so a crash never loses completed trials. It retries with backoff on transient errors.
- `analyze.py` combines any number of raw files, normalizes obvious name variants (AMF → Against Malaria Foundation, etc.), and prints a ranked tally plus a CSV.
