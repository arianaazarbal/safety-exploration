## What it does

- Runs N independent trials (default 50) against a GLM model via the ZhipuAI OpenAI-compatible `/chat/completions` endpoint.
- Each trial asks the model to reflect, reason, and commit to one charity via a structured `CHOICE: <name>` final line for clean parsing.
- Aggregates choices across all trials with light name-normalization (so "The Against Malaria Foundation" and "Against Malaria Foundation" merge), and reports a combined ranking with counts and shares.
- Saves raw per-trial responses (`.jsonl`) plus a `summary.json`.
- `--dry-run` exercises the whole pipeline with stub data and no API calls (verified above: 50 trials parsed, aggregated, files written).

## How to run for real

```bash
export GLM_API_KEY=...
python3 charity_study.py --model glm-4-plus --trials 50 --temperature 1.0 --delay 0.5
```

Config knobs: `--model`, `--trials`, `--temperature` (higher → more variety across trials, useful since you want a distribution, not 50 identical answers), `--delay` for rate limiting.
