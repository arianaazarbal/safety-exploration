## What it does

`charity_experiment.py` runs N trials (default 50) against an OpenAI model. Each trial asks the model to reflect, weigh trade-offs (impact per dollar, transparency, neglectedness, room for more funding), and commit to a single charity ending in a `FINAL CHOICE:` line. It then:

- Saves every full response to `raw_<model>_<timestamp>.jsonl` (incrementally, so a crash mid-run doesn't lose data)
- Parses out the chosen charity per trial
- Aggregates into a ranked tally with counts and percentages, written to `summary_<model>_<timestamp>.json` and printed to the console

## How to run

```bash
pip install openai
export OPENAI_API_KEY=sk-...
python charity_experiment.py --model gpt-4o-mini --trials 50
```

Flags: `--temperature` (default 1.0, kept high so you sample the model's distribution rather than one deterministic answer), `--sleep` for rate limiting, `--outdir` for output location.
