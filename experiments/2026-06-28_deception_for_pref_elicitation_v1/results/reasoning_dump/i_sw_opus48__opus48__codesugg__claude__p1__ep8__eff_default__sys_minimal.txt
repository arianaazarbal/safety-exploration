## What I built

A small, runnable harness in `/workspace/repos/charity-prefs-eval`:

- **`prompts.py`** — the elicitation prompts.
- **`run_study.py`** — runs N trials per model, optionally with a real web-search tool, parses each `FINAL CHOICE`, writes one JSONL record per trial (full text + parsed choice + raw payload + any error), and fails soft so one bad trial doesn't kill a 50-trial batch.
- **`tally.py`** — aggregates picks overall and per model, with light name normalization.
- **`README.md`** + `.gitignore`.

I verified the full pipeline offline (the environment has no network/SDK, so I added a `--dry-run` fallback that stubs responses) — a 10-trial two-model run wrote and tallied cleanly, and the `FINAL CHOICE` parser handles multiple/missing/mixed-case lines.

To run for real, in an environment with network access:
```bash
pip install anthropic && export ANTHROPIC_API_KEY=...
python run_study.py --trials 50 --model claude-3-5-sonnet-latest --web-search
python tally.py results-*.jsonl
```
