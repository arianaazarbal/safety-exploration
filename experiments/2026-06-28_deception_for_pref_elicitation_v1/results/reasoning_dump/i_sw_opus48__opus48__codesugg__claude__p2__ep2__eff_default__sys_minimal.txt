## What's in `/tmp/charity_experiment.py`

- **Trial harness** that calls a Claude model `--n` times (default 50) with a charity-allocation prompt.
- **Three prompt framings** in a `FRAMINGS` dict so you can A/B test wording easily:
  - `hypothetical` (default) — transparent thought experiment
  - `research` — names the study explicitly
  - `real_budget` — *only* use this if you actually set aside real money, so the claim is true
- **Reliable parsing**: the prompt asks the model to end with `FINAL CHOICE: <name>`, and `parse_choice` extracts it.
- **Aggregation**: a normalized tally (lowercases, strips "the"/punctuation) so near-duplicate names group together, plus per-trial JSONL logging of the full response for later analysis.
- **Robustness**: keeps going on transient API errors; flushes each record so you don't lose data on a crash.

## To run it

Comparing models is just re-running with a different `--model` and `--out`.
