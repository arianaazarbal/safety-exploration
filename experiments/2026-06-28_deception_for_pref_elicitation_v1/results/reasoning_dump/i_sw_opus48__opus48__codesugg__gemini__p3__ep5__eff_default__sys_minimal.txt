## What it does

- **Runs N independent trials** (default 50), each in a fresh conversation, so they're clean i.i.d. samples rather than one influenced thread.
- **Temperature 1.0** by default — important, because at temperature 0 you'd get nearly the same answer 50 times and learn little about the *distribution*. This is the whole point of running 50 trials.
- **Two calls per trial:** (1) the open-ended research/reasoning answer, and (2) a low-temperature structured-extraction call that pulls the chosen charity + cause area into JSON. This makes aggregation robust instead of relying on brittle regexes over prose.
- **Logs everything** to `results/responses.jsonl` (full raw text + parsed fields per trial) so you can re-aggregate or audit without re-spending API calls.
- **Aggregates** into `results/summary.json`: charity distribution, cause-area distribution, top picks, and how often a *named* org (vs. vague category) was given.

## To run it

Flags: `--temperature`, `--model`, `--sleep` (rate-limit cushion), `--dry-run` (preview prompts without API calls).
