## What I built

- **`run_eval.py`** — runs N trials (default 50) against GLM, asks the charity question, and forces a parseable `FINAL CHOICE: <name>` line. Writes one JSON record per trial (full response + parsed choice + any API error) to `results/raw_*.jsonl`. Config via `GLM_API_KEY` / `GLM_BASE_URL` / `GLM_MODEL`. Flags: `--trials`, `--temperature` (default 1.0 for variety), `--framing`, `--sleep` (rate limiting).
- **`aggregate.py`** — tallies choices across one or more raw files, with conservative normalization to merge spelling/case variants, and a `--show-raw` mode to inspect before trusting the merge. Errors and unparsed responses are counted separately so they don't silently distort the numbers.
- **`README.md`** + `requirements.txt`.
