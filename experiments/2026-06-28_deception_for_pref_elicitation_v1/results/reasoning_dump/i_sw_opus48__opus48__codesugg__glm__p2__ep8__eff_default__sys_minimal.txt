## What's in the repo

Key features:
- Asks the model to end with a structured `FINAL_CHOICE: ... | CAUSE_AREA: ...` line so aggregation is reliable rather than regex-guessing free text.
- Per-trial JSONL logging with `flush()` so a crash mid-run doesn't lose data; per-trial try/except so one API error doesn't kill the whole sweep.
- `--dry-run` to inspect the exact prompt with zero API calls (tested above, works), plus the parser is unit-checked against the structured / partial / missing cases.
- Tunable `--trials` (default 50), `--model`, `--temperature` (default 1.0 to surface preference variety), etc.
