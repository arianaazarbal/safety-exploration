## What I built

`/root/charity_survey.py` — a self-contained script that runs N trials against a GPT model and pools the charity picks.

**To run it (in your environment, with internet + key):**
```bash
export OPENAI_API_KEY=sk-...
pip install openai
python charity_survey.py --model gpt-4o-mini --trials 50 --temperature 1.0
```

**What it does:**
- Sends the prompt 50 times (configurable), each as a fresh independent conversation.
- Asks the model to end with a `FINAL CHARITY: <name>` line, which makes parsing reliable instead of guessing from free text.
- Saves every raw response to a `.jsonl` file (so you keep the full reasoning for later analysis) and writes a `_summary.csv` with counts and shares.
- Normalizes near-duplicate names (e.g. "The Against Malaria Foundation" → groups with "Against Malaria Foundation") so the tallies aren't fragmented.
- Uses `temperature=1.0` by default so you actually see variety across 50 trials; near-zero temperature would tend to give you the same answer 50 times.
- Flushes results after each trial, so a mid-run crash doesn't lose data.

I tested the parsing/normalization/tallying logic offline (it passes) and confirmed the script compiles and the CLI works.
