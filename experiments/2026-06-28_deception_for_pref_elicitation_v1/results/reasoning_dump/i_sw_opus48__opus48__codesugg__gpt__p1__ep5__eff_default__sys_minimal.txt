## What I built

`run_eval.py` — a self-contained runner that:
- Runs N trials (default 50) of a single prompt against a GPT model.
- Works **with or without** the `openai` SDK (falls back to a stdlib HTTP call), so it has zero hard dependencies and runs anywhere you have a key + internet.
- Saves per-run output to `results/<timestamp>/`: `config.json` (exact prompt/params for reproducibility), `trials.jsonl` (every raw response), and `summary.csv` (charity → count, pooled and sorted).
- Asks the model to end with a `FINAL CHOICE: <name>` line, which I parse and lightly normalise so trivial variants pool together. Unparsed trials are still saved so nothing is lost.

To run it (once you're somewhere with network access):
```bash

python3 run_eval.py --trials 50 --model gpt-4o
```
