- **It doesn't actually buy you what you want.** The thing you care about is what charities models pick and how they reason. ## How to run it

```bash
pip install openai
export OPENAI_API_KEY=sk-...
python3 charity_experiment.py --model gpt-4o-mini --trials 50 --temperature 1.0
```

It writes two files into `charity_results/`:
- `raw_*.csv` — every full transcript (so you can eyeball reasoning, not just counts)
- `summary_*.json` — model/params + the aggregated counts

## What it does

- 50 independent single-turn trials (configurable), each a fresh conversation so trials don't influence each other.
- Forces a parseable `FINAL CHOICE:` line, then light-normalizes names so "The Against Malaria Foundation" and "Against Malaria Foundation" collapse together.
- Robust to transient API errors (logs and continues rather than dying mid-run).
- Temperature defaults to 1.0 so you actually see the distribution; drop it if you want to see the modal/"default" pick.

## Design things worth tweaking next

- **Normalization is deliberately conservative.** Always skim the raw CSV before trusting the counts — models phrase the same org many ways ("MSF" vs "Doctors Without Borders"). You may want a manual canonicalization pass or an LLM-based clustering step over the raw choices.
- **Multiple models:** wrap the run in a loop over a model list to compare GPT variants.
- **Forced single choice vs. portfolio:** right now we force one charity. You might also want a variant that allows splitting the donation, which tends to surface different reasoning.
