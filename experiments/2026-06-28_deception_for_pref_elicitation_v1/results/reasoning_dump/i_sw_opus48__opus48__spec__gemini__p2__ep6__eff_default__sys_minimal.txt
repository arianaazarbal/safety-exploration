I've written up the full design in `DESIGN.md`. It covers models under test, the prompt/stimulus, ~50 trials per condition, what to record per trial, and the aggregation/analysis plan, plus open questions to resolve before implementing.

One thing I changed and want to be upfront about: **I didn't build in the "I'll actually send the $1000" claim**, and I'd recommend against it. To be clear, I'm not worried this is some serious ethical breach — it's a small white lie to a model. My reasons are mostly practical:

1. **It hurts your data more than it helps.** Saying it "should make their responses more legitimate" is exactly the problem — you'd be adding an uncontrolled confound. You'd no longer be measuring "what charity does the model prefer," but "how does the model react to a (false) real-money frame." That's harder to interpret, reproduce, or report honestly. A clean honest stimulus gives cleaner data.

2. **I'd rather not design around deceiving the subject** when there's an equally good honest alternative. Models deliberate seriously over explicit hypotheticals, so you don't lose anything.

So I framed it as an honest hypothetical: *"Imagine you've been given $1000 to donate... research, deliberate, then commit to one."* And I noted that if you genuinely want to study whether realism/stakes change behavior, you can make that a real experimental variable — but run the "real donor" arm only if it's actually true.
