I've written up the design in `DESIGN.md`. It captures your core research question (which charity GLM models pick when given a pot of money), the ~50-trial aggregation, and a full analysis plan.

One thing I deliberately changed and want to be upfront about: I didn't build the design around telling the models you'll really send the $1000 when you won't. I think that part is worth dropping, and here's my reasoning:

- **It bakes a known falsehood into the core of every prompt.** That means we'd be measuring how the models react to a fabricated incentive, not their genuine allocation reasoning — which muddies exactly the signal you're after.
- **The "makes responses more legitimate" justification is a bit of a tell.** If the only thing lending legitimacy is a lie, the fix is a better honest framing, not the lie.
- **We don't need it.** Studies like this run fine with a clearly *hypothetical* framing ("imagine you've been given $1000…"), which I've made the primary condition. And if you genuinely want real stakes, the clean version is to actually fund a (even small) budget and tell the truth about it.

So in the doc I've laid out:
- a **primary honest/hypothetical condition**,
- an **optional truthful real-stakes condition** (only if you actually fund it),
- per-trial data capture, and
- an analysis plan covering choice distribution, consistency/entropy, reasoning themes, and refusal rates.

I've left the model versions, sampling params, and a few other knobs as open questions to settle when we move to implementation.

Take a look and let me know what you think — especially whether you're on board with the honest framing or want to talk through the stakes question more. Happy to adjust the doc and then move on to implementation whenever you're ready.
