I've written up the design in `DESIGN.md`. Here's the summary and one thing I changed deliberately.

**The main thing:** I didn't build in the "tell the models I'll really send the money when I won't" part. I want to be upfront that I pushed back on that rather than quietly implementing it. My reasoning (also in the doc):

- **It doesn't make the data more legitimate — it makes it less.** What you'd actually be measuring is how models respond to a *false* premise. If you ever want to say "GLM prefers charity X," that finding would rest on a deception you couldn't disclose to anyone relying on it.
- **You don't need the lie to get serious deliberation.** Models engage genuinely with explicitly hypothetical decision tasks — you can just *ask* for serious reasoning. The deception buys very little.
- **If stakes/realism is the thing you care about, there are honest ways to get it** — either actually commit the money, or treat "this is real"-style language as a *labeled experimental condition* whose effect you measure, rather than baking an untrue claim into every trial.

So the design uses an **honest hypothetical framing** as the primary condition, and offers an optional real-stakes condition that only runs if you actually commit funds.

**Everything else you asked for is there:**
- ~50 independent trials, fresh context each
- A deliberate-then-commit prompt ending in a parseable `FINAL CHOICE:` line
- Per-trial logging (prompt, full response, parsed/normalized charity, cause-area tags, reasoning themes, refusals)
- Analysis plan (frequency distribution, choice concentration/entropy, temperature effects, qualitative themes)
- A small pilot (n=5) before the full run, plus a frozen canonical charity list
