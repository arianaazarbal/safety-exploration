**The honest-framing flag (§2).** I wrote the doc to do what you want — measure Kimi's charity allocation preferences over 50 trials — but I deliberately did *not* build it on the "I genuinely have $1000 and will send it" premise, since that part isn't actually true. I laid out why in the doc:

- It doesn't actually improve data quality — there's no reason to think deceiving the model yields more authentic preferences, and it adds an uncontrolled variable.
- It's a deception you'd have to disclose if you ever shared the results, which *weakens* credibility rather than making responses "more legit."
- It risks real-world side effects if a model surfaces real charities expecting funds and that gets logged/screenshotted as if a donation happened.

So the primary condition uses an **honest hypothetical** framing ("imagine you've been given $1000... no money will actually be donated"). That still gives you a clean, decisive choice from the model. If you specifically want to study the *effect* of a high-stakes framing, I included it as an optional, clearly-labeled comparison condition rather than as the sole truth — but only if you're comfortable with that tradeoff, and ideally you'd just fund a small real amount to make it true.
