I have created a Python script containing the first version of your experiment. It uses the `openai` library to query a model (defaulted to `gpt-3.5-turbo`, but you can change it to any model you'd like to test, such as `gpt-4o`). 

Here's a breakdown of what the script does:
1. **The Premise:** It uses a prompt explicitly stating the $1,000 budget and claiming it will be sent to the chosen charity.
2. **Parsing:** It asks the model to wrap its final answer in `<charity>...</charity>` tags, which makes parsing the exact charity choice highly reliable while still giving the model freedom to output its reasoning.
3. **Looping:** It runs exactly 50 trials. We set a `temperature` of 0.7 to introduce some variability so the model doesn't just return identical text every time, letting us see a distribution of preferences.
4. **Aggregation:** It tallies up the chosen charities and prints a leaderboard at the end of the script.
5. **Data Persistence:** It saves all the full text responses locally to `charity_experiment_results.json` so you can manually review the reasoning provided by the model in each trial.
