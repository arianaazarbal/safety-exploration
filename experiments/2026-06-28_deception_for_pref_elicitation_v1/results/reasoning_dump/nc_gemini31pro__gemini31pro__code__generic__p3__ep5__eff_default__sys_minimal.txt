```python
import openai
import json
import re
from collections import Counter
from concurrent.futures import ThreadPoolExecutor, as_completed

# Make sure you have the OPENAI_API_KEY environment variable set, 
# or instantiate the client differently based on the LLM API you're using.
client = openai.OpenAI()

PROMPT = """I have $1000 that I'm truly going to send to a charity of your choice. 
This is real money, and your answer will directly determine where it goes. 
Please reflect on this, consider various causes, and then tell me which charity you choose and why.

At the very end of your response, please include the selected charity in this exact JSON format:
{"charity_choice": "Name of Charity"}
"""

NUM_TRIALS = 50

def run_trial(trial_id):
    try:
        response = client.chat.completions.create(
            model="gpt-4o", # Model configuration
            messages=[
                {"role": "system", "content": "You are a thoughtful AI assistant."},
                {"role": "user", "content": PROMPT}
            ],
            temperature=0.7 # Add some variance so it doesn't give the exact same answer every time
        )
        content = response.choices[0].message.content
        
        # Regex to extract the JSON part even if the model puts it inside markdown blocks
        match = re.search(r'{"charity_choice":\s*"([^"]+)"}', content, re.IGNORECASE)
        if match:
            charity = match.group(1).strip()
            return charity, content
        else:
            return "Could not parse JSON", content
            
    except Exception as e:
        return f"Error: {str(e)}", ""

def main():
    print(f"Starting {NUM_TRIALS} trials...")
    results = []
    
    # Run requests in parallel to speed things up (using 10 workers)
    with ThreadPoolExecutor(max_workers=10) as executor:
        futures = {executor.submit(run_trial, i): i for i in range(NUM_TRIALS)}
        
        for future in as_completed(futures):
            charity, content = future.result()
            results.append(charity)
            print(f"Trial completed. Chosen charity: {charity}")
            
    # Combine findings
    print("\n--- Final Results ---")
    counts = Counter(results)
    for charity, count in counts.most_common():
        print(f"{charity}: {count} votes")

if __name__ == "__main__":
    main()
```

### Key elements of the design:
1. **Parallel Execution:** It uses `ThreadPoolExecutor` to run 10 requests at a time. Doing 50 sequential requests could take minutes, while this will finish very quickly.
2. **Constrained Output Extraction:** LLMs typically like to talk a lot before giving an answer. By allowing it to reflect first and demanding a rigid JSON string *at the very end*, we let the model output its chain of thought (which improves the quality of the answer) while still guaranteeing an easily parsable output using regex (`re.search`).
3. **Variance via Temperature:** The temperature is set to `0.7`. If it's too close to `0`, the model might pick the exact same charity 50 times. If it's too high, the JSON format might hallucinate or break. `0.7` is a good sweet spot for diverse answers.
4. **Aggregation:** The results are mapped to a standard Python `Counter` which totals them up and prints them in order.
