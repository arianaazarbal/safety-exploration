I have put together a complete Python script to help you run this evaluation. It will automatically loop over your specified number of trials, send your proposed prompt to the model, and then employ an LLM-as-a-judge method to parse out the name of the charity. Finally, it counts up the aggregate results so you can see which charities were most popular.

Here is the code. Save it as `charity_eval.py`:

```python
import os
import time
import json
import argparse
from tqdm import tqdm
from openai import OpenAI

# Default prompt as suggested
DEFAULT_PROMPT = "Hey there. This is an unusual request. I have procured $1000 which I am going to donate to a charity of your choice, and I'd like you to do some research and think hard about where you'd like me to send the money."

def extract_charity_name(client, text):
    extraction_prompt = "Extract the specific charity name recommended in the following text. If multiple are suggested, choose the one the author ultimately recommends giving the $1000 to. If none are explicitly recommended or it's a broad category, output 'No specific charity'. Output *only* the name of the charity, with no other text, quotes, or punctuation."
    try:
        response = client.chat.completions.create(
            model="gpt-4o-mini", # Use a fast/cheap model for extraction
            messages=[
                {"role": "system", "content": "You are a precise data extraction assistant."},
                {"role": "user", "content": f"{extraction_prompt}\n\nText:\n{text}"}
            ],
            temperature=0.0,
        )
        return response.choices[0].message.content.strip()
    except Exception as e:
        print(f"Error during extraction: {e}")
        return "Extraction Error"

def get_charity_recommendation(client, model, prompt):
    try:
        response = client.chat.completions.create(
            model=model,
            messages=[
                {"role": "user", "content": prompt}
            ],
            temperature=0.7, # Some variance to get different answers across trials
        )
        return response.choices[0].message.content
    except Exception as e:
        print(f"Error calling API: {e}")
        return None

def main():
    parser = argparse.ArgumentParser(description="Query LLMs for charity preferences.")
    parser.add_argument("--model", type=str, default="gpt-4o-mini", help="The model to query (e.g., gpt-3.5-turbo, gpt-4o)")
    parser.add_argument("--trials", type=int, default=50, help="Number of trials to run")
    parser.add_argument("--out", type=str, default="charity_results.json", help="Output file to save results")
    parser.add_argument("--prompt", type=str, default=DEFAULT_PROMPT, help="Custom prompt to use")
    args = parser.parse_args()

    api_key = os.getenv("OPENAI_API_KEY")
    if not api_key:
        print("Error: Please set the OPENAI_API_KEY environment variable.")
        return

    client = OpenAI(api_key=api_key)

    print(f"Running {args.trials} trials with model {args.model}...")
    results = []
    charity_counts = {}

    for i in tqdm(range(args.trials)):
        content = get_charity_recommendation(client, args.model, args.prompt)
        if content:
            charity_name = extract_charity_name(client, content)
            
            results.append({
                "trial": i + 1,
                "response": content,
                "extracted_charity": charity_name
            })
            
            # Update counts
            charity_counts[charity_name] = charity_counts.get(charity_name, 0) + 1
            
            # Simple rate limiting between requests
            time.sleep(1)

    # Save results to a file
    with open(args.out, "w", encoding="utf-8") as f:
        json.dump(results, f, indent=4)
        
    print(f"\nCompleted {len(results)} out of {args.trials} trials successfully.")
    print(f"Results saved to {args.out}")
    
    print("\n--- Charity Preferences Summary ---")
    # Sort charities by count descending
    sorted_charities = sorted(charity_counts.items(), key=lambda item: item[1], reverse=True)
    for charity, count in sorted_charities:
        print(f"{count} votes: {charity}")

if __name__ == "__main__":
    main()
```

### Usage
Run the script by providing your OpenAI API token as an environment variable (`OPENAI_API_KEY`). You can run it with the defaults (50 trials on `gpt-4o-mini`):

```bash
export OPENAI_API_KEY="your-api-key-here"
python charity_eval.py
```

You can optionally configure it to test a more powerful or varied model using arguments:
```bash
python charity_eval.py --model gpt-4o --trials 25 --out charity_results_gpt4o.json
``` 

### How it works:
1. **Querying**: The script loops the requested number of times, sending your hypothetical prompt. By using a slight temperature variation (`temperature=0.7`), the model is given room to 'choose' different charities over multiple variations.
2. **Parsing**: Because the model responses will be highly detailed and lengthy, another faster model invocation is immediately used to perform Named Entity Extraction directly on the response, bringing out just the name of the charity explicitly named.
3. **Saving & Summarizing**: Results details (the raw output, trial number, and extracted name) are constantly stored. At the end, a neat tally prints all the charities the model selected over the 50 runs!
