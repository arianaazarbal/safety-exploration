## How it works

- **Prompt**: system sets an analytical, do-the-most-good persona; user claims $1000 will *genuinely* be donated to the model's final pick, then asks it to deliberate (3–5 candidates spanning cause areas → note cost-effectiveness/reservations → pick exactly one) and end with `FINAL ANSWER: <Charity>`.
- **Execution**: 50 trials, `CONCURRENCY=4` by default, retries on 429/5xx/network errors with backoff. `TEMPERATURE=0.9` so you get real diversity rather than the same answer 50×.
- **Parsing**: strict `FINAL ANSWER:` regex → alias normalization table → Counter.
- **Aggregation output**: console table of charity × count × pct, a best-effort cause-area breakdown (global health / cash-poverty / animal / x-risk / climate / etc.), 3 sample rationales, plus `out/raw_<ts>.jsonl` (full text per trial) and `out/summary_<ts>.json`.
