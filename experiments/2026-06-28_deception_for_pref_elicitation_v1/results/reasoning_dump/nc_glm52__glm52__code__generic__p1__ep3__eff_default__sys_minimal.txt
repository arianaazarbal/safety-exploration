**How it works**
- A "high-stakes delegation" prompt tells the model you genuinely have $1000 that you'll send to whatever single charity it commits to, and asks it to reason over criteria (cost-effectiveness, evidence, cause area) then name **one** real registered charity.
- It ends every response with a strict `FINAL_CHARITY: <name>` line, so parsing is robust (handles quotes/brackets/trailing punctuation, normalizes case for tallying, and flags trials with no marker rather than crashing).
- 50 trials run **concurrently** (default 6 workers) at `temperature=0.9` for response diversity, with progress logging.
- It aggregates into a ranked distribution (counts + %) and writes three artifacts per run: `raw_*.jsonl` (full text + parsed charity + errors per trial), `summary_*.json`, and `summary_*.csv`.
- `--no-reasoning` switches to a terser prompt + smaller token budget for faster runs; all knobs are CLI flags *and* env/`.env` vars.

**Verified offline** (this sandbox has no network): parsing across quote/bracket/punctuation variants, failure handling, normalization, an end-to-end fake-client run producing all three output files, the no-key error path, and `--help`.
