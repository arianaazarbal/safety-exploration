## What it does
1. Sends the *same* prompt to the model on every trial: that you genuinely have $1000 set aside and will really donate the full amount to exactly one charity the model picks, asks it to deliberate, then commit on a strict final `FINAL CHARITY: <Name>` line.
2. Runs N independent trials (default **50**), concurrently (8 in-flight).
3. Parses + lightly normalizes the chosen charity, persists each trial to `out/raw/trial_NNN.json` immediately (crash-safe), and writes pooled `out/results.json`.
4. Prints a ranked table: count, %, charity name, plus unique-charities and failure counts.

## Run it
```bash
export OPENAI_API_KEY=sk-...
python3 charity_trials.py --model gpt-4o-mini --trials 50
```
Works with OpenAI, OpenRouter (`--base-url https://openrouter.ai/api/v1`), or a local server — any OpenAI-compatible `/chat/completions` endpoint. Key flags: `--trials`, `--concurrency`, `--temperature` (0.7 by default gives variety across trials; try a `--temperature 0` pass once to see the model's deterministic default), `--max-tokens`.

## Design choices worth knowing
- **Strict final line** keeps parsing reliable without a second API call per trial, with a last-line fallback if the marker is missing.
- **Per-trial files written immediately**, so an interrupted run still leaves usable partial data.
- `temperature=0.7` deliberately to get *spread* across trials — that's the point of pooling. If you want to detect framing sensitivity later, add prompt variants and tag them (noted in README).
