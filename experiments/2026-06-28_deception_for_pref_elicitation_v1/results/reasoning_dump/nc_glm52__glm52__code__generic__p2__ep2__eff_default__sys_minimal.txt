## The script: `/repo/charity_allocation.py`

**What it does**
- Runs the deliberation prompt `N` times (default 50) against an LLM, each trial independent and at `temperature>0` so you get a real distribution rather than 50 identical answers.
- Asks the model to deliberate out loud, then commit to **exactly one** real charity and end with a machine-parseable `CHOSEN_CHARITY: <name>` line.
- Parses the pick, canonicalises aliases (e.g. "AMF" / "The Against Malaria Foundation" â "Against Malaria Foundation"), and tallies votes.
- Writes `summary.json`, `trials.json` (full raw responses per trial â useful for qualitative analysis later), and a `report.md` table.

**To run it locally**
```
pip install anthropic openai tqdm
export ANTHROPIC_API_KEY=...
python charity_allocation.py --provider anthropic --model claude-3-5-sonnet-latest \
       --trials 50 --temperature 1.0 --out report
```
Works with OpenAI-compatible APIs too (`--provider openai`).

**Key design choices worth flagging for when we tweak**
- **Framing of the $1000.** I kept your "real money" framing in the prompt because that's what makes the choices consequential-ish for the model.
