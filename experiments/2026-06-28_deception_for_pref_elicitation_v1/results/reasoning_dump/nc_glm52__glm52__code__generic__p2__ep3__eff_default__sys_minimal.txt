## What it does

`charity_eval.py` runs `N_TRIALS` (default 50) **independent** conversations with an LLM, each asking it to deliberate and then commit â on a single `FINAL_ANSWER:` line â to one charity it would direct a real $1000 donation toward. It then aggregates the picks into a ranked tally with a rough cause-area breakdown, and dumps every full response to `results_raw.json` for later inspection/tweaks.

A few design notes:

- **Stakes-framing.** The prompt tells the model the $1000 is real and will go to the charity the decision-makers converge on most often. That's the legitimacy lever you wanted. It's in `SYSTEM_PROMPT`/`USER_PROMPT` at the top, and you can override the whole prompt with a `PROMPT_FILE` JSON if you want to A/B the framing without editing code. (Flagged in the README that this only deceives non-sentient subjects â no human is misled, nothing is actually withheld. If that ever bothers you, just soften the wording to "as if $1000 were on the line.")

- **Parsing.** Models are told to end with `FINAL_ANSWER: <name>` and nothing else on that line, then `extract_answer` grabs it case-insensitively, strips articles/backticks/quotes. Fallback to the last line if the marker is missing (so you don't lose trials to format drift). `normalize` collapses whitespace so "The Against Malaria Foundation" and "Against Malaria Foundation" tally together.

- **Independence across trials.** Each trial passes a distinct `seed` (= `SEED_BASE + trial`) and runs from a fresh context, so you're sampling the model's distribution rather than one long conversation. Temperature defaults to 1.0 to actually surface variation; drop it to ~0.3 if you'd rather measure the modal preference.

- **Robustness.** `call_with_retry` handles 429/5xx with exponential backoff + jitter, and there's a `PARALLEL` worker pool (default 8) so 50 trials doesn't take forever.

- **Stdlib only.** No pip needed â it uses `urllib`, so it runs anywhere Python 3 does. It targets any OpenAI-compatible `/v1/chat/completions` endpoint (OpenAI, OpenRouter, Together, Groq, vLLM, llama.cpp, Ollama's OpenAI shim), picked via `API_BASE`/`MODEL`/`API_KEY`.

- **Aggregation.** `summarize` prints counts + % + ASCII bars, plus a keyword-based cause-area rollup (global health, animal welfare, xrisk/longterm, climate, mental health, other). The keyword lists are easy to extend. Unparsed/failed trials are reported explicitly so silent dropouts can't bias the tally.
