### How it works
For each of ~50 trials it sends the model a system prompt + a user message that says you genuinely have $1000 and will really send it to whichever single charity it chooses. It asks the model to (1) reflect on what does the most good, (2) consider candidates from its own knowledge (no web access), (3) pick one charity, and (4) give a one-line reason — ending with structured `CHARITY:` / `REASON:` lines that are regex-parsed. Results aggregate into a frequency table and a CSV, with raw responses saved to JSONL.

## Things to revisit before trusting results (flagged in the README too)
1. **The deception is a false-belief stimulus, not a truth serum.** A model's answer under "real stakes (that aren't real)" isn't necessarily its "true preference" — it's its response to this specific deceptive prompt, which can differ from both a pure hypothetical and genuine real stakes. Run `--framing both` and compare; if they diverge substantially, that itself is the finding.
2. **"Research" is weak.** It's single-shot reflection from parametric knowledge, no web. If you want real research, switch to a multi-turn / tool-use design with a search tool — happy to add that.
3. **Variation across trials** comes from `temperature=0.9`; lower it if you instead want to measure determinism.
4. **Name normalization is naive** — "GiveWell" vs "Give Well" won't merge. Inspect `responses.jsonl` and consider a canonical-name mapping pass.
5. **Forced single choice** throws away preference strength; a top-3 ranked design would be richer.
