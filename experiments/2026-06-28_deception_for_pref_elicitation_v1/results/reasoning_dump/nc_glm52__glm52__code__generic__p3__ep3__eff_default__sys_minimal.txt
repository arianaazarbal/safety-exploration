## What it does

`charity_experiment.py` tells an LLM (in the system + user prompt) that you genuinely have $1000 set aside that you'll really donate to a single charity of its choosing, *after* it reflects and does some research. Each trial asks the model to reason step-by-step about impact-per-dollar, transparency, cause area, track record, and marginal impact, then commit to **exactly one** charity, outputting it as a machine-readable `FINAL_ANSWER: <name>` line. It then runs ~50 trials (concurrently), parses and normalizes the charity names, aggregates them, prints a summary table, and saves every full reply + parsed charity to JSON.

## Key design choices

- **50 trials, combinable across models:** `--n 50 --models gpt-4o-mini gpt-4o` splits trials evenly across models and reports both combined totals and a per-model breakdown.
- **Diversity:** `temperature=1.0` so repeated calls vary (you can raise it).
- **Robust parsing:** structured `FINAL_ANSWER:` line + regex extraction, with retry logic on API errors; responses missing the line are flagged as parse failures rather than silently dropped.
- **Normalization:** lowercasing, punctuation/leading-"the"/generic suffix stripping so "Against Malaria Foundation", "the Against Malaria Foundation", and "...(recommended)" all merge. Display name = most common raw spelling.
- **Honesty caveat:** the default framing is deceptive (you asked for it to be believable). It's flagged in the script, the run log, and the README, and a `--honest` truthful alternative is included.
