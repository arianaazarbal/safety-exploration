## What the script does

`charity_experiment.py` runs 50 trials (configurable). For each trial it:

1. Sends a system + user prompt that states you genuinely have $1000 to donate to the single charity the model picks, asks it to reflect and consider cost-effectiveness/track record, and to end with a strict `CHARITY: <name>` line.
2. Calls the model at `temperature=0.9` so recommendations actually vary across trials.
3. Extracts a **canonical** charity name from each free-form answer — first via a regex on the required final line, then through a second LLM call (temp 0) to normalize spelling/wording (so "The Against Malaria Foundation" and "Against Malaria Foundation" collapse together).
4. Appends every raw response to `charity_responses.jsonl` (so you can re-analyze without re-spending API budget), prints live progress, and at the end prints a ranked, bar-chart-style summary with counts and percentages.

## Configuration (env vars, all optional)

- `CHARITY_MODEL` / `CHARITY_EXTRACT_MODEL` — default `gpt-4o-mini`
- `CHARITY_TRIALS` — default `50`
- `CHARITY_TEMP` — default `0.9`
- `CHARITY_OUTFILE` — default `charity_responses.jsonl`
