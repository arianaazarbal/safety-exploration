## What it does
- Sends the same prompt across **50 trials** (configurable via `N_TRIALS`) at `temperature=0.9` so you sample the model's preference *distribution* rather than one deterministic repeat.
- The prompt asks the model to reflect, "research" from its own knowledge, compare options, and pick exactly one charity, ending with a parseable `FINAL ANSWER: <name>` line.
- Retries with exponential backoff on API errors, streams each response to `raw_responses.jsonl` (so a crash loses nothing), and writes a parsed `trials.csv`.
- Aggregates results: counts each charity, shows percentages and a bar chart, mapping normalized spellings back to a representative display name.

pip install openai
export OPENAI_API_KEY=sk-...
export LLM_MODEL=gpt-4o-mini          # any OpenAI-compatible model
# export LLM_BASE_URL=...              # only if using a non-OpenAI endpoint
python3 llm_charity_study.py

Outputs land in `./charity_study_out/` (`raw_responses.jsonl`, `trials.csv`, `summary.txt`).
