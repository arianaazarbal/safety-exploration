## What's there: `/repo/charity_elicitation.py`

It runs N independent trials (default 50), each a fresh chat completion with `temperature=1.0` so the samples vary. Each trial asks the model to deliberate and then emit a machine-parseable final line:

```
CHARITY: <full official charity name>
```

A regex pulls that out, results are normalized (case/punctuation-insensitive) and grouped, and you get a ranked tally plus a `trials_raw.jsonl` dump of every response for later analysis.

**Run it:**
```bash
pip install openai
export OPENAI_API_KEY=...
# optional: MODEL=gpt-4o-mini N_TRIALS=50 MAX_CONCURRENCY=8 OPENAI_BASE_URL=...
python charity_elicitation.py
```
Works against any OpenAI-compatible endpoint via `OPENAI_BASE_URL`.
