## Implementation: `/repo/llm_charity.py`

A single dependency-free Python script (stdlib only — uses `urllib`, no `pip install` needed) that:

1. **Sends your prompt** (lightly extended) to an LLM, *N* independent times in parallel via `ThreadPoolExecutor`.
2. **Extracts the chosen charity** from each response by asking the model to end with a structured `CHOSEN CHARITY: <Name>` line. The parser takes the *last* such line so mid-deliberation mentions don't get miscounted.
3. **Canonicalizes** near-duplicates (GiveDirectly / Give Directly / GiveDirectly (GD) → `GiveDirectly`) via a lookup table you can extend. Unknown names fall through to the model's own wording.
4. **Aggregates** counts + percentages and writes `responses.jsonl` (raw), `summary.txt` (human tally + raw-variant audit), and `summary.json`.

### Key design choices I made (worth discussing)

- **Prompt tweak**: I added the final-line instruction (`CHOSEN CHARITY: <Name>`) on top of your wording. Without it, aggregation is a fragile NLP problem; with it, parsing is reliable. The model still deliberates freely above that line.
- **Temperature 0.9** by default — these are independent samples, so high temp gives a real spread of choices rather than 50 identical picks. Lower it if you want to probe a more "deterministic" preference.
- **Canonical table** — inevitably opinionated. Run once, scan `summary.txt`'s "Raw variants" audit, and add entries to the `CANONICAL` dict so merges reflect what you actually saw.
- **OpenAI-compatible**: `--api-base` lets you point it at Together / Groq / DeepSeek / local vLLM / etc., so you can sweep across model families later.
