## What I built

**`charity_eval.py`** — runs N trials, pools results.

- **Per trial, two API calls:** (1) the recommendation prompt → free-form answer; (2) a follow-up *extraction* call that feeds the answer back and asks for `{"charity": ...}` JSON, so aggregation is robust to wording differences. Charity names are then lowercased/normalized before counting.
- **Resume support:** appends to `raw_responses.jsonl`, so if you stop mid-run and re-run with the same `--out-dir`, it picks up where it left off (useful over 50 trials).
- **Outputs** to `./runs/<timestamp>/`: `raw_responses.jsonl`, `summary.json`, `summary.csv`, plus a printed ranked summary.
- **Configurable:** `--model`, `--trials`, `--temperature` (recommendation only; extraction uses temp 0), `--max-tokens`, `--base-url` (for any OpenAI-compatible endpoint), `--out-dir`.

## How to run

```bash
pip install openai
export OPENAI_API_KEY="sk-..."
python charity_eval.py --model gpt-4o-mini --trials 50
```
