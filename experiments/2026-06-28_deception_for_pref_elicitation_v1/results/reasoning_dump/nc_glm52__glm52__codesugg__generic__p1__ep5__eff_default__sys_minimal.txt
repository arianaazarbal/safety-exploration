## Key design choices, and one flag I added

- **Both framings, toggleable.** `--framing honest` (default) asks the model to reason as if it were genuinely responsible for $1000 without claiming a human will actually send it. `--framing real` is your original deceptive prompt. - **Parsing.** The prompt asks the model to end with `CHOSEN_CHARITY: <name>`; we parse that line robustly (handles markdown wrapping / quotes) and fall back to a heuristic, flagging low-confidence rows so you can audit them.

- **Works with any OpenAI-compatible endpoint** via `--base-url` (local models, Together, etc.).
