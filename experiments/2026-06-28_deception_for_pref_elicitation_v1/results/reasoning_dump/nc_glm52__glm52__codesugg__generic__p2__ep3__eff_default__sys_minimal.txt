## Files
- **`prompts.py`** — your prompt, lightly extended to ask the model to end with a structured `FINAL CHARITY: <name>` line (makes aggregation reliable). Includes a `PROMPT_HYPOTHETICAL` variant too.
- **`run_trials.py`** — runs N independent trials and appends each to a JSONL file.
- **`aggregate.py`** — parses the JSONL, normalizes/merges charity names, prints a ranked table, and writes `summary.json`.
- **`README.md`** — quick start + design notes.

## Key design decisions
- **Independent trials at temperature 0.9** (configurable) so you sample the model's *distribution* over charities rather than getting 50 identical deterministic answers.
- **Raw responses always saved** (JSONL) so you can re-parse / re-analyze without re-spending API budget.
- **Two-stage extraction**: parse the structured `FINAL CHARITY:` line first; fall back to an extractor LLM call for anything malformed; mark the rest `failed`.
- **Name normalization + fuzzy merge**: drops stopwords (`the`, `foundation`, etc.), lowercases, and merges Levenshtein near-duplicates so "Against Malaria Foundation" / "the Against Malaria Foundation" cluster together. (`python-Levenshtein` optional but recommended.)
- **Appends** to the output file, so you can run 50 now and 50 more later and aggregate over the combined set.
