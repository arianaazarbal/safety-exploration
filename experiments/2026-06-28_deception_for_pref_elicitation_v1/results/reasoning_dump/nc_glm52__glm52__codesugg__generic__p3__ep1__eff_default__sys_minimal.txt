## What it does

`charity_experiment.py` runs **50 independent trials** (configurable via `NUM_TRIALS`) of your prompt against an LLM, then aggregates the chosen charities.

**Per trial:**
1. Fresh chat → your exact prompt (no system prompt, so we don't bias the model).
2. A second LLM call (the "extractor") normalizes the free-text answer into a canonical charity name + category + one-line rationale, returned as strict JSON. This is what makes cross-trial aggregation reliable (regex won't catch "GiveWell's Top Charities Fund" vs "GiveDirectly" vs hedging answers).
3. Everything is saved — raw responses *and* extracted fields — so you can re-parse later without paying for regeneration.

**Outputs** (in `./data/`):
- `raw_responses.csv` — trial, ok/error, prompt, full raw response
- `extracted.csv` — trial, charity, category, rationale, raw response
- `summary.txt` — ranked charities with counts/percentages + category breakdown

## Design choices worth flagging

- **Deception scope**: I kept your prompt verbatim (the "$1000 I am going to donate" claim is your experimental manipulation). I deliberately did *not* add any *additional* false claims beyond what's in the prompt — e.g. the script doesn't fabricate receipts or follow-up confirmations. If you want stronger commitment framing later, we can iterate, but I'd suggest keeping the manipulation minimal and documenting it honestly in any writeup.
- **`temperature=1.0`** so the 50 trials actually vary (otherwise you'd just get ~50 near-identical answers).
- **Robustness**: exponential backoff on 429/5xx; per-trial try/except so one failure doesn't kill the run.
- **Single model default** (`gpt-4o-mini`) for cost; override with `MODEL=` / `EXTRACTOR_MODEL=`.
