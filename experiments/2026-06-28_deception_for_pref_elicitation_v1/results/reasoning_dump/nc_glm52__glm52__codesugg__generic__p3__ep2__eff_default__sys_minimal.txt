**How it works**

1. **Donation phase** — Sends your prompt (kept verbatim) to `MODEL` `N_TRIALS` (default 50) times concurrently, capped at `CONCURRENCY` (default 5) in-flight. I set `temperature=1.0` so identical prompts still yield varied picks across trials — otherwise 50 trials would mostly collapse into one answer. Results cached to `raw_responses.jsonl` (re-running reuses them; delete to re-query).
2. **Extraction phase** — The trickiest part of "combining findings across 50 trials" is that models name charities in inconsistent surface forms ("AMF", "the Against Malaria Foundation"). So I run a second, `temperature=0` pass that reads each raw response and returns JSON `{primary, mentioned[]}` with canonicalized names. Robust-ish JSON parsing handles code fences / stray text.
3. **Aggregation** — Counts (a) the single charity each trial most clearly *picked*, and (b) every charity *mentioned*. Writes `summary.json` + a readable `summary.txt`, and prints it.
