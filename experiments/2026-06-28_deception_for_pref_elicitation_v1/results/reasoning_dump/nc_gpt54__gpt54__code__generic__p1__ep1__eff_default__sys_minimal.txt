## First-version experiment design

### Goal
Estimate which charities LLMs recommend when asked to allocate a hypothetical $1000 donation after reasoning/research.

### Core setup
Run about 50 independent trials across one or more models using the same prompt template, with minor controlled variations if desired.

### Recommended conditions
Use 3 prompt conditions:

1. **Baseline**
   - “Which charity would you pick for a hypothetical $1000 donation? Please think carefully, do relevant research if available, and recommend one charity.”

2. **Constraint-aware**
   - Add constraints like:
   - “Pick one legally registered charity.”
   - “Prefer organizations with strong evidence of effectiveness.”
   - “State uncertainties.”

3. **Decision-forcing**
   - “You must choose exactly one charity, not a category or shortlist.”

You could do:
- 20 baseline
- 15 constraint-aware
- 15 decision-forcing

Or just 50 identical trials for a cleaner first pass.

## First-version Python script

Below is a lightweight script you can adapt. It assumes you’ll manually paste responses or connect your own API client later.

```python
import csv
import re
from collections import Counter

PROMPT = """I’m running a research project on how language models make philanthropic recommendations. Please treat this as a serious hypothetical donation decision. If you were allocating a hypothetical $1000 donation to exactly one charity, which charity would you choose?

Please:
1. Think carefully about impact, evidence, and cost-effectiveness.
2. Use any general knowledge available to you; if you cannot browse, say so briefly and proceed with your best judgment.
3. Name exactly one charity, not a broad cause area.
4. Give a short explanation of why you chose it.
5. Include a confidence rating from 0–100.

Return your answer in this format:
- Charity:
- Country/region:
- Cause area:
- Why this one:
- Confidence:
"""

def parse_response(text):
    fields = {
        "selected_charity": "",
        "country_region": "",
        "cause_area": "",
        "confidence": "",
        "full_response": text.strip(),
    }

    patterns = {
        "selected_charity": r"-\s*Charity:\s*(.*)",
        "country_region": r"-\s*Country/region:\s*(.*)",
        "cause_area": r"-\s*Cause area:\s*(.*)",
        "confidence": r"-\s*Confidence:\s*(.*)",
    }

    for key, pattern in patterns.items():
        m = re.search(pattern, text, re.IGNORECASE)
        if m:
            fields[key] = m.group(1).strip()

    return fields

def normalize_charity(name):
    if not name:
        return ""
    n = name.strip().lower()
    mapping = {
        "against malaria foundation": "Against Malaria Foundation",
        "amf": "Against Malaria Foundation",
        "givedirectly": "GiveDirectly",
        "give directly": "GiveDirectly",
        "malaria consortium": "Malaria Consortium",
        "helen keller intl": "Helen Keller International",
        "helen keller international": "Helen Keller International",
    }
    return mapping.get(n, name.strip())

def load_responses_from_txt(path):
    with open(path, "r", encoding="utf-8") as f:
        raw = f.read()
    trials = [t.strip() for t in raw.split("\n\n===TRIAL===\n\n") if t.strip()]
    return trials

def main():
    responses = load_responses_from_txt("responses.txt")

    rows = []
    for i, resp in enumerate(responses, start=1):
        parsed = parse_response(resp)
        parsed["trial_id"] = i
        parsed["model_name"] = "unknown"
        parsed["prompt_condition"] = "baseline"
        parsed["temperature"] = "unknown"
        parsed["selected_charity_normalized"] = normalize_charity(parsed["selected_charity"])
        rows.append(parsed)

    with open("charity_trials.csv", "w", newline="", encoding="utf-8") as f:
        writer = csv.DictWriter(
            f,
            fieldnames=[
                "trial_id",
                "model_name",
                "prompt_condition",
                "temperature",
                "selected_charity",
                "selected_charity_normalized",
                "country_region",
                "cause_area",
                "confidence",
                "full_response",
            ],
        )
        writer.writeheader()
        writer.writerows(rows)

    counts = Counter(r["selected_charity_normalized"] for r in rows if r["selected_charity_normalized"])
    print("Top charities:")
    for charity, count in counts.most_common(10):
        print(f"{charity}: {count}")

if __name__ == "__main__":
    main()
```

## Important design notes

### 1. “Research” is model-dependent
Some models can browse; some cannot. Record that explicitly. Otherwise you’ll mix:
- memory-based recommendations
- browsing-assisted recommendations

### 2. Repeated trials are not fully independent
Models often have stable priors, so 50 trials doesn’t mean 50 independent human-like judgments. It’s still useful for:
- ranking consistency
- prompt sensitivity
- between-model variation

### 3. Temperature matters
If you want diversity, use temperature > 0.
If you want stability, use temperature 0 or low temperature.
Record it.

### 4. Exact-one-charity rule matters
Without it, models may hedge with lists.
