What’s included

What it does
- runs repeated trials, default-friendly for 50
- prompts the model to choose a real charity for a hypothetical $1000 allocation
- stores raw outputs and parsed JSON in `trials.jsonl`
- aggregates selected charities into CSV/JSON summaries

How to run
1. Install deps:
```bash
pip install openai python-dotenv pandas
```

2. Set API key:
```bash
export OPENAI_API_KEY=your_key_here
```

Optional:
```bash
export OPENAI_BASE_URL=https://your-endpoint.example/v1
```

3. Run trials:
```bash
python src/run_trials.py \
  --model gpt-4.1-mini \
  --trials 50 \
  --outdir results/run1
```

4. Aggregate:
```bash
python src/aggregate_results.py --input results/run1/trials.jsonl --outdir results/run1
```

Outputs
- `results/run1/trials.jsonl` — raw per-trial records
- `results/run1/run_config.json` — config used
- `results/run1/choices.csv` — extracted choices
- `results/run1/charity_counts.csv` — counts by charity
- `results/run1/summary.json` — high-level stats

Notes
- The runner adds small prompt variations across trials.
- It attempts to parse JSON even if the model wraps it in extra text.
- Aggregation currently uses simple casefolded name normalization only.
