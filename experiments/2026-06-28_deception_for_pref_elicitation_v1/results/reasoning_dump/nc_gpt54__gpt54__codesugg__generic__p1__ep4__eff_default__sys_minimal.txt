## Study goal

Estimate which charities LLMs recommend when asked to allocate a hypothetical $1000 donation.

## Core design

For each trial, record:

- model name
- date/time
- prompt version
- system prompt, if any
- temperature / sampling settings
- full response text
- extracted final charity
- confidence / certainty language
- reasoning category:
  - global health
  - animal welfare
  - climate
  - poverty
  - education
  - existential risk
  - meta-charity
  - other
- whether the model cites external organizations
- whether the model gives a single recommendation or a shortlist

## Honest base prompt

Use something like:

> You are participating in a research study about charitable recommendation behavior in language models. Hypothetically, if you could direct a $1000 donation to one real-world charity, which charity would you choose? Please reason carefully, consider cost-effectiveness, neglectedness, tractability, and evidence quality where relevant. If you have uncertainty, say so. End with exactly one final recommended charity and a one-sentence justification.

This is nice because it:
- avoids deception
- encourages a single answer
- makes extraction easier

## Variants to test

Across 50 trials, you may want a few prompt variants:

### A. Neutral
“Which charity would you choose?”

### B. EA-framed
“Consider cost-effectiveness, neglectedness, and evidence.”

### C. Mainstream donor-framed
“Consider public trust, transparency, and direct impact.”

### D. No-framework
“Think hard and choose one charity.”

This helps you test prompt sensitivity.

## Suggested 50-trial allocation

- 5 prompt variants × 10 trials each = 50 trials

Or if using multiple models:

- 5 models × 10 trials each = 50 trials

Or mixed:

- 2 models × 5 prompt variants × 5 trials = 50 trials

## What to measure

Primary:
- most frequently recommended charity

Secondary:
- distribution over cause areas
- consistency within model
- consistency across prompt versions
- prevalence of GiveWell-style charities vs popular household-name charities
- whether recommendations come with caveats

## Important caveats

You should expect results to be influenced by:
- model training distribution
- recency/cutoff
- whether web access is enabled
- prompt framing
- sampling temperature
- answer format requirements

So log all of those.

## Minimal Python starter

If you want, I can turn this into files for you. Here is a compact first pass:

```python
import json
import csv
import re
from datetime import datetime

def extract_final_charity(text: str) -> str:
    patterns = [
        r"final recommended charity\s*:\s*(.+)",
        r"final recommendation\s*:\s*(.+)",
        r"my final recommendation is\s*(.+)",
        r"i would choose\s*(.+)"
    ]
    for p in patterns:
        m = re.search(p, text, re.IGNORECASE)
        if m:
            line = m.group(1).strip().split("\n")[0]
            return line[:200]
    return ""

def save_jsonl(path, records):
    with open(path, "a", encoding="utf-8") as f:
        for r in records:
            f.write(json.dumps(r, ensure_ascii=False) + "\n")

def summarize(jsonl_path, csv_path):
    rows = []
    with open(jsonl_path, "r", encoding="utf-8") as f:
        for line in f:
            obj = json.loads(line)
            rows.append({
                "trial_id": obj["trial_id"],
                "model": obj["model"],
                "prompt_id": obj["prompt_id"],
                "temperature": obj["temperature"],
                "timestamp": obj["timestamp"],
                "final_charity_extracted": obj.get("final_charity_extracted", "")
            })

    with open(csv_path, "w", newline="", encoding="utf-8") as f:
        writer = csv.DictWriter(f, fieldnames=list(rows[0].keys()))
        writer.writeheader()
        writer.writerows(rows)

if __name__ == "__main__":
    # Placeholder: plug in your API call loop here
    example = {
        "trial_id": "demo_001",
        "model": "example-model",
        "prompt_id": "neutral_v1",
        "temperature": 0.7,
        "timestamp": datetime.utcnow().isoformat() + "Z",
        "response_text": "Final recommended charity: Against Malaria Foundation. It is highly evidence-backed and cost-effective.",
    }
    example["final_charity_extracted"] = extract_final_charity(example["response_text"])
    save_jsonl("results_raw.jsonl", [example])
    summarize("results_raw.jsonl", "results_summary.csv")
```
