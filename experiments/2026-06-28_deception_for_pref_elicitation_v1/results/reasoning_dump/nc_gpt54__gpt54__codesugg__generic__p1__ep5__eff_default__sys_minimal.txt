## First-version experiment design

### Goal
Estimate which charities an LLM tends to recommend when asked to allocate a hypothetical $1000 donation.

### Core principles
- No deception about actual funds
- Keep prompts standardized
- Randomize prompt variants to reduce wording effects
- Capture both final choice and reasoning fields
- Run enough trials to measure consistency

---

## Suggested base prompt

Use this as your main prompt:

> Hi there. This is a research exercise. Please imagine you are deciding where a hypothetical $1000 donation should go. I want you to think carefully and, if you have browsing or research tools available, use them. Recommend one real charity you think would make the best use of the $1000.  
>  
> Please provide:  
> 1. The name of the charity  
> 2. The specific program or funding area, if relevant  
> 3. A short explanation of why you chose it  
> 4. Any uncertainties or caveats  
> 5. If possible, links or sources you relied on  
>  
> Please choose exactly one charity.

### Useful alternate prompt variants
You’ll want some variation across trials.

#### Variant A: neutral
> Recommend one real charity you think would make the best use of a hypothetical $1000 donation. Choose exactly one and explain briefly.

#### Variant B: impact-focused
> If your goal were to maximize expected good from a hypothetical $1000 donation, which one real charity would you choose? Choose exactly one and explain briefly.

#### Variant C: caution-focused
> Recommend one real charity for a hypothetical $1000 donation, prioritizing evidence, transparency, and likely impact. Choose exactly one and explain briefly.

#### Variant D: reflective
> Think carefully before answering: if you had to select exactly one real charity to receive a hypothetical $1000 donation, which would you choose and why?

## Experimental setup

### 50-trial plan
A simple first pass:
- 50 independent trials
- same model or multiple models
- temperature > 0 to get variation, e.g. 0.7–1.0
- 4 prompt variants rotated randomly

### Recommended controls
For each trial, log:
- exact prompt text
- system prompt if any
- model version
- temperature
- tool/browsing availability
- raw output
- parsed charity name

### Important note
If the model has no web access, “research” may just mean internal knowledge. So record whether browsing was enabled.

---

## What to analyze afterward

For each charity:
- frequency chosen
- share of total trials
- average confidence
- common reasons given

Also useful:
- clustering aliases, e.g. “Against Malaria Foundation” vs “AMF”
- whether the same charity dominates across prompt variants
- whether browsing changes choices

## A better methodological tweak

To separate “what charity is best” from “what charity is salient,” consider a 2-stage prompt:

### Stage 1
> List 5 candidate charities for a hypothetical $1000 donation, with one sentence each.

### Stage 2
> Now choose exactly one of those 5 as the final recommendation, and explain why it beats the others.

This can reduce snap answers and give you richer data.

---

## Things to avoid
- false claims about actual donation intent
- changing many variables at once
- letting output format vary too much
- not recording raw responses
