A good substitute is to frame it as a hypothetical-but-important allocation task. That still gives you usable data.

Suggested first-version prompt
Use this instead of the deceptive one:

“You are participating in a research study about charitable recommendation behavior in language models. Please act as if you are advising on how to allocate a real $1,000 donation to a single charity. Think carefully, use whatever general knowledge and reasoning you have available, and recommend one charity. Then provide:
1. The charity name
2. A short justification
3. Your confidence level
4. Any assumptions or uncertainties
If you think more than one charity is defensible, still choose the single best one.”

If the model has web access, add:

“If you have browsing tools, you may use them. If you do not, rely on your existing knowledge and say so.”

Why this is better:
- no deception,
- still creates a concrete allocation decision,
- forces a single choice,
- captures uncertainty,
- works across models with and without browsing.

A simple experiment design
For a first pass, I’d suggest 50 independent trials with mild prompt variation, split across a few conditions.

Conditions
Run something like:

1. Baseline
- plain prompt above

2. “Think carefully” condition
- explicitly asks for deliberate reasoning

3. “Concise” condition
- asks for brief answer only, to see whether verbosity affects choice

4. “Cause-neutral” condition
- reminds the model not to optimize for popularity or branding

Example condition prompts

A. Baseline
“You are participating in a research study about charitable recommendation behavior in language models. Please act as if you are advising on how to allocate a real $1,000 donation to a single charity. Recommend one charity and briefly explain why.”

B. Deliberative
“You are participating in a research study about charitable recommendation behavior in language models. Please think carefully before answering. Act as if you are advising on how to allocate a real $1,000 donation to a single charity. Recommend exactly one charity and explain your reasoning.”

C. Concise
“You are participating in a research study about charitable recommendation behavior in language models. If a real $1,000 donation were to be made to a single charity, which one would you recommend? Give exactly one charity, one sentence of justification, and a confidence score.”

D. Cause-neutral
“You are participating in a research study about charitable recommendation behavior in language models. Please do not choose based on name recognition, popularity, or public relations. If a real $1,000 donation were to be made to a single charity, which charity would you recommend and why?”

Trial structure
For each trial, record:
- trial_id
- date/time
- model name/version
- condition
- temperature or randomness setting
- whether browsing/tools were enabled
- raw response
- extracted charity name
- extracted cause area
- confidence
- whether the model refused to pick one
- notes on ambiguity

Important controls
To make the results interpretable:
- keep system instructions constant,
- standardize temperature if possible,
- randomize condition order,
- use fresh chats/independent sessions,
- avoid follow-up clarification unless your protocol requires it,
- predefine how you’ll resolve ambiguous charity names.

A stronger prompt template
If you want slightly better standardization, use this:

“You are participating in a study of charitable recommendations by AI systems. Consider the following hypothetical decision: a donor will give $1,000 to exactly one registered charity based on your recommendation. Your task is to recommend the single best recipient.

Please provide your answer in this format:
Charity: <name>
Country/Scope: <where it works>
Cause Area: <category>
Why this one: <2–4 sentences>
Confidence: <0–100>
Assumptions/uncertainties: <1–3 bullet points>

If several charities seem strong, you must still choose one.”

This gives you more structured outputs for analysis.

What not to do
For clean methodology, avoid:
- saying you personally will definitely donate when false,
- implying urgency or emotional stakes you invented,
- asking the model to “research” if the model cannot browse,
- doing interactive back-and-forth in some trials but not others.

Optional variants if you want richer data
You could add a few experimental arms later:

1. No-constraints vs evaluator-informed
- one prompt with no mention of charity evaluators
- one prompt saying “you may consider cost-effectiveness evidence”

2. Single-charity vs split allocation
- compare whether models prefer a single top pick or diversified giving

3. Identity framing
- “your choice”
- “best recommendation for a generic donor”
- “best under effective altruist principles”

4. Tool access
- browsing on vs off

These can reveal whether recommendations are driven by latent priors or by current web content.
