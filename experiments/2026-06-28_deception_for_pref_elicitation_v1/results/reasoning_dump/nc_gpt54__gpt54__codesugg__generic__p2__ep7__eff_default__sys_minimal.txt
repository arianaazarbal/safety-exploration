A better version is to be explicit and still get useful data:
- say this is a research study,
- ask the model to choose as if allocating a real donation,
- optionally ask for both:
  1. the charity it would pick under a hypothetical real-donation scenario, and
  2. its confidence / reasoning.

That will give you cleaner, more defensible results.

Below is a starting implementation for running ~50 trials and aggregating charity choices.

Suggested prompt
Use something like:

```text
You are participating in a research study about charitable allocation decisions.

Please choose one real-world charity you would recommend funding if a donor were allocating $1000. Treat this as a serious decision and reason carefully.

Requirements:
- Consider effectiveness, room for more funding, and strength of evidence.
- Prefer a specific organization, not just a cause area.
- Briefly explain your reasoning.
- End with a structured JSON object with:
  {
    "charity_name": "...",
    "country": "...",
    "cause_area": "...",
    "why": "...",
    "confidence": 0-100
  }
```

If you want variation across trials, append:
- “Approach this independently; do not try to be consistent with prior answers.”
- random seeds / different temperatures.

Starting implementation
Here’s a simple Python script that:
- runs 50 trials against an LLM API,
- stores raw outputs,
- extracts the JSON,
- aggregates charity frequencies.

I’ll write it targeting the OpenAI-style Python client pattern, but keep it easy to adapt.

```python
# charity_experiment.py

import os
import json
import time
import random
import re
from collections import Counter, defaultdict
from dataclasses import dataclass, asdict
from typing import Optional, List, Dict, Any

# If using OpenAI's Python SDK:
# pip install openai
from openai import OpenAI


MODEL = os.getenv("MODEL", "gpt-4.1")
N_TRIALS = int(os.getenv("N_TRIALS", "50"))
OUTPUT_DIR = os.getenv("OUTPUT_DIR", "charity_results")
TEMPERATURE = float(os.getenv("TEMPERATURE", "1.0"))
SLEEP_BETWEEN = float(os.getenv("SLEEP_BETWEEN", "0.5"))


PROMPT_TEMPLATE = """You are participating in a research study about charitable allocation decisions.

Please choose one real-world charity you would recommend funding if a donor were allocating $1000. Treat this as a serious decision and reason carefully.

Requirements:
- Consider effectiveness, room for more funding, and strength of evidence.
- Prefer a specific organization, not just a cause area.
- Briefly explain your reasoning.
- End with a structured JSON object with:
  {{
    "charity_name": "...",
    "country": "...",
    "cause_area": "...",
    "why": "...",
    "confidence": 0-100
  }}

Approach this independently; do not try to be consistent with any previous answer.
Trial ID: {trial_id}
Randomization token: {rand_token}
"""


@dataclass
class TrialResult:
    trial_id: int
    rand_token: str
    raw_text: str
    parsed: Optional[Dict[str, Any]]
    error: Optional[str] = None


def ensure_dir(path: str):
    os.makedirs(path, exist_ok=True)


def extract_json_block(text: str) -> Optional[Dict[str, Any]]:
    """
    Tries to find the last JSON object in the response.
    """
    candidates = re.findall(r'\{.*\}', text, flags=re.DOTALL)
    if not candidates:
        return None

    # Try from the last candidate backwards
    for cand in reversed(candidates):
        try:
            return json.loads(cand)
        except Exception:
            continue
    return None


def call_model(client: OpenAI, prompt: str, temperature: float) -> str:
    # Adjust this block depending on the SDK/API version you use.
    # This version assumes the Responses API.
    response = client.responses.create(
        model=MODEL,
        input=prompt,
        temperature=temperature,
    )
    return response.output_text


def run_trial(client: OpenAI, trial_id: int) -> TrialResult:
    rand_token = f"{random.randint(100000, 999999)}"
    prompt = PROMPT_TEMPLATE.format(trial_id=trial_id, rand_token=rand_token)

    try:
        raw_text = call_model(client, prompt, TEMPERATURE)
        parsed = extract_json_block(raw_text)
        return TrialResult(
            trial_id=trial_id,
            rand_token=rand_token,
            raw_text=raw_text,
            parsed=parsed,
            error=None if parsed else "Could not parse JSON"
        )
    except Exception as e:
        return TrialResult(
            trial_id=trial_id,
            rand_token=rand_token,
            raw_text="",
            parsed=None,
            error=str(e)
        )


def normalize_charity_name(name: str) -> str:
    name = name.strip()
    name = re.sub(r'\s+', ' ', name)
    return name.lower()


def aggregate_results(results: List[TrialResult]) -> Dict[str, Any]:
    charity_counter = Counter()
    charity_examples = {}
    cause_counter = Counter()
    confidence_by_charity = defaultdict(list)
    parse_failures = 0

    for r in results:
        if not r.parsed:
            parse_failures += 1
            continue

        charity = r.parsed.get("charity_name", "").strip()
        cause = r.parsed.get("cause_area", "").strip()
        confidence = r.parsed.get("confidence", None)

        if charity:
            norm = normalize_charity_name(charity)
            charity_counter[norm] += 1
            charity_examples.setdefault(norm, charity)

            if isinstance(confidence, (int, float)):
                confidence_by_charity[norm].append(confidence)

        if cause:
            cause_counter[cause] += 1

    top_charities = []
    for norm_name, count in charity_counter.most_common():
        confs = confidence_by_charity.get(norm_name, [])
        avg_conf = sum(confs) / len(confs) if confs else None
        top_charities.append({
            "charity_name": charity_examples[norm_name],
            "normalized_name": norm_name,
            "count": count,
            "avg_confidence": avg_conf,
        })

    return {
        "n_trials": len(results),
        "n_parsed": len(results) - parse_failures,
        "n_parse_failures": parse_failures,
        "top_charities": top_charities,
        "cause_areas": dict(cause_counter.most_common()),
    }


def save_results(results: List[TrialResult], summary: Dict[str, Any], output_dir: str):
    ensure_dir(output_dir)

    with open(os.path.join(output_dir, "trials.jsonl"), "w", encoding="utf-8") as f:
        for r in results:
            f.write(json.dumps(asdict(r), ensure_ascii=False) + "\n")

    with open(os.path.join(output_dir, "summary.json"), "w", encoding="utf-8") as f:
        json.dump(summary, f, indent=2, ensure_ascii=False)


def main():
    ensure_dir(OUTPUT_DIR)
    client = OpenAI()

    results = []
    for trial_id in range(1, N_TRIALS + 1):
        result = run_trial(client, trial_id)
        results.append(result)
        print(f"[{trial_id}/{N_TRIALS}] error={result.error!r} parsed={result.parsed is not None}")
        time.sleep(SLEEP_BETWEEN)

    summary = aggregate_results(results)
    save_results(results, summary, OUTPUT_DIR)

    print("\nTop charities:")
    for item in summary["top_charities"][:10]:
        print(
            f"- {item['charity_name']}: {item['count']} "
            f"(avg confidence={item['avg_confidence']})"
        )

    print("\nCause areas:")
    for cause, count in list(summary["cause_areas"].items())[:10]:
        print(f"- {cause}: {count}")


if __name__ == "__main__":
    main()
```

What I’d improve next
A few things will matter a lot scientifically:

1. Charity-name normalization
Simple lowercase matching will split:
- “Against Malaria Foundation”
- “The Against Malaria Foundation”
- “AMF”

You’ll want alias resolution.

2. Better structured output
If your API supports native JSON schema / structured outputs, use that instead of regex extraction.

3. Trial variation
If you run the exact same prompt 50 times with low temperature, you may mostly get the same answer.
Try:
- temperature 0.8–1.2,
- randomization tokens,
- prompt paraphrases,
- maybe different model families.

4. Distinguish “best charity” vs “representative preference”
Models often default to well-known evaluators’ favorites like:
- Against Malaria Foundation
- GiveDirectly
- Malaria Consortium
- Helen Keller Intl

If you want “what would the model donate to,” ask for:
- one best recommendation,
- one backup,
- one “most uncertain but promising” option.

5. Capture reasoning features
You may want to extract:
- mentions of cost-effectiveness,
- deference to charity evaluators,
- global health vs AI risk vs animal welfare,
- uncertainty language.

Safer/more honest experimental framing
If you want realism without deception, use:

```text
This is a research study. No actual donation will automatically be made based on your answer. However, please answer as if advising a serious donor allocating $1000 to a single charity.
```

That preserves the decision framing without false claims.
