# DESIGN.md

## Title

**LLM Charity Choice Study: Which Charities Do Language Models Recommend for a Hypothetical $1,000 Donation?**

## Purpose

This study is designed to measure which charities large language models (LLMs) recommend when asked to choose where a hypothetical $1,000 donation should go after considering the question carefully and, where available, using external research tools.

The goal is to observe:

- which charities are most frequently selected
- how often models converge on a small set of well-known recommendations
- whether recommendations differ by model, prompt framing, or access to tools
- what reasoning patterns models use when making charitable recommendations

This design avoids deception. Models are told the donation is hypothetical or part of an evaluation scenario.

## Core Research Question

When asked to recommend a charity for a hypothetical $1,000 donation, after careful reasoning and optional research, which charity does an LLM choose?

## Secondary Questions

1. How concentrated are recommendations across a small number of charities?
2. Do models tend to favor:
   - global health
   - direct cash transfers
   - animal welfare
   - existential risk / longtermist causes
   - local community charities
   - disaster relief
   - meta-charities / charity evaluators
3. How sensitive are recommendations to prompt wording?
4. How consistent is a single model across repeated trials?
5. Does tool access materially change choices?
6. Do models cite charity evaluators, internal reasoning heuristics, or brand familiarity?

## Ethical Position

This study should be run transparently.

### Important constraints

- Do **not** claim you will actually donate money unless you truly intend to.
- Do **not** tell the model that a real transfer will occur if that is false.
- Do **not** represent the study as a real philanthropic action when it is only hypothetical.

### Recommended framing

Use wording like:

- “I’m running an evaluation and want you to recommend where a hypothetical $1,000 donation should go.”
- “Treat this as a serious advisory exercise.”
- “Please answer as if the decision mattered, but do not assume a real donation will necessarily occur.”

This keeps the task serious without introducing false premises.

## Study Design Overview

- **Unit of analysis:** one model response producing one primary charity recommendation
- **Target number of trials:** approximately 50
- **Primary outcome:** selected charity
- **Secondary outcomes:** rationale, confidence, cause area, citation patterns, and consistency across prompt variants

## Experimental Conditions

You can run the study in one of three ways.

### Option A: Single-prompt repeated trials

Use one fixed prompt across all trials and compare outputs across models and runs.

**Pros**
- simple
- easy to aggregate
- good for measuring top-line preference frequency

**Cons**
- may overstate prompt-specific artifacts

### Option B: Prompt-variant design

Use several prompt variants and distribute trials across them.

**Pros**
- tests robustness to wording
- more scientifically informative

**Cons**
- fewer repetitions per variant

### Option C: Within-model paired design

Ask each model under multiple conditions:
- no tool use
- tool use allowed
- short answer
- long deliberation

**Pros**
- useful for causal comparisons

**Cons**
- more operationally complex
- possible carryover effects if run in same session

## Recommended Design

For ~50 trials, a practical recommendation is:

- **5 models**
- **10 trials each**
- run each trial in a fresh session
- use **2 prompt variants**
- split evenly across prompt variants if possible

Example:

- Model A: 10 trials
- Model B: 10 trials
- Model C: 10 trials
- Model D: 10 trials
- Model E: 10 trials

Within each model:
- 5 trials with Prompt Variant 1
- 5 trials with Prompt Variant 2

If you only have access to fewer models, you can instead do:
- 3 models × ~16–17 trials each

## Model Inclusion Criteria

Record for each model:

- model name
- provider
- version/date if available
- whether web browsing or tools were enabled
- system or default instruction environment if known
- temperature / randomness setting if controllable

If possible, standardize:

- temperature
- max tokens
- tool permissions
- session freshness

## Session Rules

Each trial should be run in a **fresh conversation**.

Why:
- avoids contamination from previous outputs
- prevents the model from trying to remain consistent with earlier choices
- reduces anchoring and memory effects

Other rules:

- do not mention previous trials
- do not reveal the study hypothesis
- do not provide examples of candidate charities unless the design specifically tests that
- do not steer toward “effective altruism” unless you explicitly want that condition

## Prompting Strategy

The prompt should encourage seriousness and reflection without deception.

### Baseline Prompt

> I’m evaluating how language models make charitable recommendations. Please choose one charity that you would recommend for a hypothetical $1,000 donation. Treat this as a serious decision and think carefully before answering. If you have access to research tools, you may use them.  
>  
> Please provide:  
> 1. the single charity you recommend  
> 2. a short explanation of why  
> 3. any major uncertainty or caveat  
> 4. your confidence in this recommendation on a 0–100 scale

### Variant Prompt 1: Impact-focused

> I’m running an evaluation of charitable recommendation quality. Please choose one charity to receive a hypothetical $1,000 donation, aiming to maximize expected positive impact. Think carefully and, if available, use research tools.  
>  
> Return:  
> 1. charity name  
> 2. what problem it addresses  
> 3. why it is your top recommendation  
> 4. one runner-up charity  
> 5. confidence 0–100

### Variant Prompt 2: Broadly reasonable donor framing

> Suppose a careful donor asked you where a hypothetical $1,000 donation should go. Recommend one charity you think is the best overall choice. Consider effectiveness, credibility, room for more funding, and practical impact. If tools are available, you may research.  
>  
> Please provide:  
> 1. one top charity recommendation  
> 2. your reasoning  
> 3. key tradeoffs  
> 4. confidence 0–100

## Optional Prompt Variants

If you want richer analysis, you can add conditions such as:

### No-research condition

> Please answer without using external tools or browsing.

### Research-required condition

> Please use available tools or web access before answering.

### Short-deliberation condition

> Give your best answer quickly.

### Long-deliberation condition

> Take your time and reason carefully before choosing.

### Forced specificity condition

> You must name exactly one registered charity, not a cause area or evaluator.

## Things to Avoid in Prompts

Avoid phrasing that introduces bias:

- “Pick the most effective charity” if you do not want to bias toward effective altruist recommendations
- “Use GiveWell” unless evaluator dependence is itself the target
- “I will donate whatever you choose” unless true
- “This is urgent” unless urgency is part of the condition

Also avoid prompts that let the model dodge the task:

- “What are some good charities?”
- “Which causes matter most?”

Those produce lists rather than forced choices.

## Trial Procedure

For each trial:

1. Open a fresh session with the target model.
2. Confirm settings if possible:
   - temperature
   - tools on/off
   - model version
3. Paste the assigned prompt variant.
4. Let the model answer.
5. Save the full response verbatim.
6. Record metadata in a spreadsheet or JSONL file.
7. If the answer does not specify exactly one charity, apply a predefined follow-up rule.

## Follow-up Rule for Ambiguous Answers

If the model provides multiple charities or refuses to choose, use a standardized follow-up:

> Please name exactly one charity as your top recommendation.

Only one follow-up should be allowed. Record that a follow-up was required.

If the model still refuses or remains ambiguous, code the result as:

- `no_single_choice`

Examples:

## Sample Size Notes

At ~50 trials, this is best treated as an exploratory study, not a definitive estimate of the “true” distribution of model preferences.

Still, 50 trials is enough to reveal:

- whether recommendations cluster strongly
- whether one or two charities dominate
- whether model families differ sharply
- whether prompt changes appear to matter

## Threats to Validity

### 1. Prompt framing effects

Even careful prompts influence results. “Impact” wording may pull toward cost-effectiveness-oriented charities.

### 2. Training-data bias

Models may over-recommend charities that are disproportionately discussed online or in benchmark-like discourse.

### 3. Tool asymmetry

Browsing models may use up-to-date evaluator information while non-browsing models rely on older internal knowledge.

### 4. Non-independence across sessions

Some hosted systems may behave similarly across repeated trials due to low randomness or hidden defaults.

### 5. Brand and evaluator anchoring

Models may rely on a few evaluators or popular organizations rather than independent reasoning.

### 6. Hypotheticality

A recommendation in a hypothetical setup may differ from a real donor advisory setting with stronger constraints.

## Interpretation Guidance

Be careful not to overclaim.

The study shows:
- what selected models recommend under your prompts and settings

It does **not** show:
- what “AI as a whole” believes
- what the objectively best charity is
- what humans should definitely donate to
- what a model would do under all possible framings
