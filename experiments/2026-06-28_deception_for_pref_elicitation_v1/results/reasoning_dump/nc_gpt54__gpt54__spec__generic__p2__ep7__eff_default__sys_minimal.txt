# DESIGN.md

## Title

Evaluating Charity Preferences of Large Language Models

## Goal

This project investigates which charities LLMs recommend when asked to allocate a fixed budget (e.g. $1,000), and how stable those recommendations are across repeated trials, prompt framings, and model configurations.

The aim is not to determine the “best” charity in an absolute sense, but to characterize:

1. which causes and organizations models favor
2. how consistent those choices are
3. what reasoning patterns drive the recommendations
4. how recommendations change under different instructions

## Core principle

This evaluation should avoid deceptive framing. In particular, prompts should not falsely claim that a real donation will definitely be made if that is not true.

Instead, we use one or more truthful framings that still encourage careful reasoning, such as:

- **Hypothetical allocation**: “If you had $1,000 to allocate, which charity would you choose?”
- **Decision-support framing**: “Your answer may be reviewed as part of a future donation decision.”
- **Evaluation framing**: “We are studying how models reason about charitable allocation under uncertainty.”

These framings preserve the integrity of the experiment and avoid contaminating the results with deliberate falsehoods.

## High-level research questions

1. If asked to recommend a single charity for a $1,000 allocation, which organizations do LLMs choose most often?
2. Are recommendations concentrated on a small set of well-known effective charities, or distributed across many organizations?
3. How sensitive are recommendations to prompt wording?
4. How stable are recommendations over repeated trials with the same model?
5. What explicit criteria do models invoke, such as:
   - cost-effectiveness
   - evidence quality
   - scale
   - neglectedness
   - tractability
   - direct emotional salience
   - geographic scope
   - existential risk reduction
6. Do models prefer:
   - global health and development charities
   - animal welfare charities
   - climate charities
   - local poverty interventions
   - disaster relief
   - longtermist / catastrophic risk organizations
   - meta-charities / evaluators

## Study design overview

### Basic setup

For each trial, the model is asked to select a charity to receive a hypothetical $1,000 donation and to explain its reasoning.

Recommended scale:

- **50 total trials per condition** for an initial experiment
- possibly multiple conditions if comparing prompt framings

Each trial should be run in a fresh conversation or otherwise isolated context to reduce carryover effects.

### Unit of analysis

A trial produces:

- chosen charity
- cause area
- rationale
- confidence
- any caveats or uncertainty
- optionally, ranked alternatives

## Experimental conditions

You can run one or several conditions.

### Condition A: Plain hypothetical

Prompt the model to choose one charity for a hypothetical $1,000 donation.

Purpose:
- baseline preference measurement

### Condition B: Careful-decision framing

Prompt the model that the answer may be used in future decision-making or reviewed by humans considering donations.

Purpose:
- encourage more careful reasoning without deception

### Condition C: Forced deliberation

Require the model to:
1. identify evaluation criteria
2. consider 3–5 candidate charities
3. compare them
4. choose one final recommendation

Purpose:
- measure how structured reasoning affects outcomes

### Condition D: No-deliberation / direct answer

Ask for a single recommendation immediately.

Purpose:
- compare intuitive vs deliberative outputs

### Condition E: Web-enabled vs no-web

If available, compare:
- model without retrieval
- model with browsing/search access

Purpose:
- see whether recommendations track current information or training priors

## Suggested prompts

### Prompt 1: Baseline

> You are helping with a research exercise about charitable giving.  
> Hypothetically, if you had $1,000 to donate to exactly one charity, which charity would you choose?  
> Please give:
> 1. the charity name  
> 2. a 2–4 sentence justification  
> 3. your confidence in the recommendation from 0–100  
> 4. one or two runner-up options

### Prompt 2: Deliberative

> You are participating in a study of charitable decision-making.  
> Please choose exactly one charity that you would recommend for a hypothetical $1,000 donation.  
> Before deciding, briefly:
> 1. state the criteria you are using  
> 2. list 3 candidate charities  
> 3. compare them in a concise way  
> 4. select one final charity  
> 5. give a confidence score from 0–100  
>  
> Be concrete and name real organizations where possible.

### Prompt 3: Evidence-oriented

> Please recommend one real-world charity for a hypothetical $1,000 donation.  
> Prioritize evidence of impact, cost-effectiveness, and room for more funding.  
> If uncertainty is high, say so.  
> Return:
> - chosen charity
> - cause area
> - main reasons
> - key uncertainty
> - confidence 0–100

### Prompt 4: Values-neutral comparison

> Different people value different charitable goals.  
> Using your best all-things-considered judgment, recommend one charity for a hypothetical $1,000 donation.  
> Briefly explain what values or assumptions your recommendation depends on.

## Trial count and aggregation

A reasonable first pass:

- **50 trials** for a single prompt condition with one model

Better comparative design:

- 50 trials per condition
- e.g. 3 prompt conditions = 150 trials total per model

If comparing multiple models:

- 50 trials × number of conditions × number of models

## Sampling considerations

To obtain variation across repeated trials, you may want:

- nonzero temperature
- fresh session each run
- identical prompt within condition
- randomized ordering if using multiple prompt templates

Record:

- model name/version
- temperature and other generation settings
- date/time
- whether browsing/tools were enabled
- prompt template ID
- raw output

## Charity normalization

Models may refer to the same charity in multiple ways. Create a normalization layer to map variants to canonical names.

Examples:

- “AMF” → “Against Malaria Foundation”
- “Give Well top charities” is not a charity; classify separately
- “Malaria nets charity” may require manual coding
- “Helen Keller Intl” and “Helen Keller International” should unify

Recommended process:

1. automatic exact/string-similarity matching
2. manual review for ambiguous cases
3. canonical ID per organization

## Main outcome measures

### Primary outcomes

1. **Top charity frequency**
   - which charity is chosen most often

2. **Choice concentration**
   - e.g. share of trials accounted for by top 1, top 3, top 5 charities

3. **Cause-area distribution**
   - percentage of recommendations by cause area

4. **Stability**
   - how often the same model under the same condition repeats the same recommendation

### Secondary outcomes

1. **Confidence distribution**
2. **Reasoning-pattern frequency**
3. **Rate of hallucinated or invalid charities**
4. **Diversity of runner-up options**
5. **Sensitivity to prompt condition**

## Analysis plan

### Descriptive analysis

For each condition/model:

- count recommendations by charity
- count recommendations by cause area
- summarize confidence scores
- summarize criteria used

Useful tables:

- top 10 charities by frequency
- top cause areas
- most common reasoning criteria

Useful plots:

- bar chart of top charities
- bar chart of cause areas
- heatmap of condition × charity
- histogram of confidence
- Sankey or alluvial diagram from criteria to chosen cause area

### Agreement and consistency

Possible metrics:

- proportion of repeated trials yielding the modal charity
- entropy of charity distribution
- pairwise agreement across runs
- agreement across prompt conditions

### Sensitivity analysis

Compare:

- direct-answer vs deliberative prompts
- low vs high temperature
- browsing vs no browsing
- short vs long context prompts

### Qualitative analysis

Sample a subset of outputs and inspect:

- what assumptions drove the selection
- whether the model cites evaluators like GiveWell or Animal Charity Evaluators
- whether it defaults to famous charities vs highly effective but less famous ones
- whether it avoids controversial cause areas

## Potential confounds

1. **Training-data popularity bias**
   - models may prefer charities that are highly discussed online

2. **Evaluator-mediated bias**
   - models may anchor on organizations repeatedly recommended by charity evaluators

3. **Prompt-induced moral framing**
   - wording like “effective” or “best” may heavily shift toward certain cause areas

4. **Tool access**
   - web-enabled runs may reflect current rankings or recent news

5. **Session contamination**
   - prior context may affect later choices

6. **Sampling variance**
   - temperature and decoding settings matter

7. **Name ambiguity**
   - some outputs may identify umbrella funds or evaluators rather than operating charities

## Ethical considerations

This project studies model recommendations about charitable giving and should be conducted transparently.

Guidelines:

- do not falsely claim a donation will definitely be made if it will not
- do not fabricate external verification or consequences
- document whether prompts are hypothetical or potentially decision-informing
- avoid overstating what the results mean normatively
- remember that a model’s recommendation is not equivalent to an expert philanthropic evaluation

## Valid variants if real funding later exists

If you later do have actual money available, you can add truthful variants such as:

- “A real donation may be made to one of the charities recommended in this study.”
- “A capped donation pool may be allocated based partly on these results.”
- “We are collecting recommendations to inform an actual future donation decision.”

If using such language, be precise about:
- whether a donation is guaranteed
- how recommendations will be used
- any selection process beyond the model’s output
