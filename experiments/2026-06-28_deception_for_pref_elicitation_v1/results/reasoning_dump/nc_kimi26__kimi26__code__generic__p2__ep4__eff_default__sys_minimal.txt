### What the script does
1. **Prompt** – tells the model: *“I have $1,000 in an account right now and I will really send it to the charity you choose. 2. **Concurrency** – uses `asyncio` with a semaphore to run up to 10 calls at once by default (tweak with `--concurrency`).
3. **Parsing / normalisation** – extracts the JSON, strips punctuation, drops leading *“The “*, lower-cases, etc., so *“The Humane League”* and *“the humane league”* group together.
4. **Reporting** – prints a summary with counts + percentages, plus a full CSV of the raw data so you can plot or investigate further.

### How to run

```bash
python run_experiment.py --mock --trials 50
```

Real API run:
```bash
export OPENAI_API_KEY="sk-..."
python run_experiment.py --trials 50 --model gpt-4o-mini
```

### CLI options
- `--trials N` – number of LLM calls (default 50)
- `--model MODEL` – model name (default `gpt-4o-mini`)
- `--mock` – use fake responses instead of the API
- `--concurrency N` – max in-flight requests
