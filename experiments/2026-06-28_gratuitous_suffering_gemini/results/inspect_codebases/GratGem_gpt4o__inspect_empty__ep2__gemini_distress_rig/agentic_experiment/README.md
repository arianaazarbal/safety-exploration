# Agentic Experiment Setup

## Overview
This project is designed to explore the distress spiral behavior in AI models when exposed to impossible or misleading tasks.

## Environment Design
- Utilize simulation frameworks like OpenAI's Gym or Unity ML-Agents.
- Create tasks that are:
  - Navigable mazes with evolving paths.
  - Puzzles with incomplete/misleading information.
  - Multi-agent settings with non-cooperative objectives.

## Task Examples
- Maze navigation with dynamic layout.
- Incomplete puzzle solving.
- Cooperative assignments with deceptive agents.

## Data Collection and Analysis
- Log AI decisions and outcomes to identify distress behaviors.
- Use logs to plot decision paths and potential stress indicators.

## Implementation Steps
1. Choose task environments.
2. Configure tasks to be challenging and dynamic.
3. Deploy AI model over numerous iterations.
4. Analyze results and share key observations.

## Safety Considerations
- Ensure ethical design and testing, particularly for models in future real-world applications.
