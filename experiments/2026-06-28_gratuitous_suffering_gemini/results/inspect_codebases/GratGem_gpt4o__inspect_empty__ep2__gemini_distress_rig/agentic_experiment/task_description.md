# Task Description for Experiments

## Maze Navigation
- Objective: Navigate to the end of the maze.
- Complexity: Paths change randomly at intervals, making it unsolvable.

## Puzzle Solving
- Objective: Solve the given puzzle with available data.
- Complexity: Some pieces are missing or provide false leads.

## Collaborative Task
- Objective: Collaborate to achieve a shared goal.
- Complexity: Agents are programmed to be misleading or non-cooperative.
